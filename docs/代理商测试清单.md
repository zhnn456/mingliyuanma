## 二、SaaS 模式测试（一级代理商）

> SaaS 代理商：共享主站实例，通过 agentId 区分客户，佣金 30%

### 2.1 代理商注册

#### 2.1.1 自主注册
- [ ] 访问 `https://bazi6.cc.cd/register-agent`
- [ ] 填写：邮箱、密码、品牌名、联系人、手机号
- [ ] 提交后返回 200，提示「代理商注册成功」
- [ ] 返回数据包含：`agent.id`、`agent.referralCode`、`agent.licenseKey`
- [ ] 检查 `level` 字段值为 `saas`
- [ ] 检查 `commissionRate` 字段值为 `0.3`
- [ ] 检查 `plan` 字段值为 `trial`
- [ ] 检查 `planExpiry` 为 7 天后

#### 2.1.2 管理员创建代理商
- [ ] 管理后台 → 代理商管理 → 新建代理商
- [ ] 填写品牌名、域名、联系人、套餐等级
- [ ] 提交后代理商记录出现在列表
- [ ] 自动生成 HMAC 签名授权码
- [ ] 授权码写入 `AgentLicense` 表，`signature` 字段非空

#### 2.1.3 重复注册拦截
- [ ] 用同一邮箱再次注册 → 返回 400「该邮箱已注册」
- [ ] 同一 IP 1 分钟内注册 3 次以上 → 返回 429「注册尝试过于频繁」

### 2.2 代理商登录与后台

#### 2.2.1 登录验证
- [ ] 用代理商账号登录 `https://bazi6.cc.cd/login`
- [ ] 登录后自动跳转 `/agent`（而非 `/admin`）
- [ ] 代理商后台布局正常加载，不报错

#### 2.2.2 代理商后台功能（/agent/*）
- [ ] `/agent/dashboard` 仪表盘：显示代理商基本信息、待结算佣金、本月 GMV
- [ ] `/agent/settings` 品牌设置：能修改品牌名、Logo、联系方式
- [ ] `/agent/invite` 邀请链接：显示专属邀请链接 `https://bazi6.cc.cd/register?ref=REFXXXXXX`
- [ ] `/agent/customers` 客户列表：显示通过该代理商注册的用户
- [ ] `/agent/orders` 订单列表：显示该代理商客户的订单
- [ ] `/agent/commissions` 佣金统计：显示待结算/已结算/月度佣金
- [ ] `/agent/agent-settlements` 结算记录：显示历史结算申请
- [ ] `/agent/agent-orders` 代理订单：代理商自身付费记录
- [ ] `/agent/billing` 账单：套餐费用、续费记录
- [ ] `/agent/updates` 更新日志：系统版本更新记录

### 2.3 邀请与客户绑定

#### 2.3.1 邀请链接注册
- [ ] 复制代理商邀请链接 `https://bazi6.cc.cd/register?ref=REFXXXXXX`
- [ ] 用新邮箱通过该链接注册普通用户
- [ ] 注册成功后，新用户 `User.agentId` = 代理商 ID
- [ ] 代理商后台「客户列表」出现该用户
- [ ] 代理商后台「客户数 +1」

#### 2.3.2 直接注册（无邀请码）
- [ ] 不带 `ref` 参数直接注册
- [ ] 新用户 `User.agentId` 为空
- [ ] 不归属任何代理商

### 2.4 佣金分润

#### 2.4.1 自动分润
- [ ] 绑定代理商的客户充值灵珠（如 100 元）
- [ ] 检查 `CommissionRecord` 表新增记录：
  - [ ] `agentId` = 代理商 ID
  - [ ] `orderAmount` = 100
  - [ ] `commissionRate` = 0.3
  - [ ] `commissionAmount` = 30
  - [ ] `status` = `pending`
- [ ] 代理商后台「佣金统计」待结算佣金 +30

#### 2.4.2 结算流程
- [ ] 代理商后台「结算记录」点击「申请结算」
- [ ] 提交结算申请，填写收款银行信息
- [ ] 管理后台「结算审核」出现该申请
- [ ] 管理员审核通过 → `Settlement.status` = `approved`
- [ ] 管理员标记已打款 → `Settlement.status` = `paid`
- [ ] 代理商后台「佣金统计」已结算佣金 +30，待结算佣金 -30

### 2.5 授权码验证

#### 2.5.1 SaaS 代理商授权码
- [ ] 代理商后台「设置」页显示当前授权码 `LIC.xxx.xxx`
- [ ] 授权码格式正确：`LIC.` 前缀 + Base64 载荷 + HMAC 签名
- [ ] 试用期 7 天后授权码失效
- [ ] 续费后生成新授权码，`licenseExpiry` 延期

#### 2.5.2 授权码冻结
- [ ] 管理后台「授权码管理」找到该代理商授权码
- [ ] 点击「冻结」→ `AgentLicense.status` = `revoked`
- [ ] 代理商后台访问受限，提示「授权已冻结」
- [ ] 解冻后 → `status` = `active`，恢复正常

## 三、源码部署模式测试（二级代理商）

> 源码代理商：独立部署实例，通过授权码 + 域名绑定验证

### 3.1 源码包准备

#### 3.1.1 构建产物
- [ ] 执行 `npm run build:worker` 构建成功
- [ ] `.next/worker.js` 生成
- [ ] `.next/assets/` 静态资源生成
- [ ] 前端 JS 已混淆（检查 `_next/static/chunks/*.js` 是否为乱码）

#### 3.1.2 交付包内容
- [ ] `.next/` 完整目录
- [ ] `.env.production` 模板（含占位符 `REPLACE_ME_*`）
- [ ] `package.json`（含部署脚本）
- [ ] `prisma/migrations.sql`（数据库初始化脚本）
- [ ] `DEPLOY.md` 部署文档
- [ ] 源码不包含 `.env`、`.env.production` 真实配置、`NEXTAUTH_SECRET`

### 3.2 二级代理商部署

#### 3.2.1 初始部署
- [ ] 代理商收到源码包，解压到本地
- [ ] 修改 `.env.production`：
  - [ ] `name` = 代理商自定义项目名
  - [ ] `NEXTAUTH_URL` = 代理商域名
  - [ ] `APP_LICENSE_KEY` = 管理员下发的授权码
  - [ ] `APP_AGENT_ID` = 代理商 ID
  - [ ] `APP_BOUND_DOMAIN` = 绑定域名
- [ ] 执行 `bash deploy.sh` 部署到代理商自己的服务器
- [ ] 访问代理商域名，首页正常加载

#### 3.2.2 授权码验证
- [ ] 部署后首次访问，中间件触发 `/api/agent/sync`
- [ ] 子站向中央服务器（主站）发送授权码 + 域名 + agentId
- [ ] 中央服务器验证：
  - [ ] 授权码 HMAC 签名有效
  - [ ] 域名与 `AgentLicense.domain` 匹配
  - [ ] 授权码未过期、未冻结
  - [ ] agentId 存在且 active
- [ ] 验证通过 → `Agent.lastSyncAt` 更新，`systemStatus` = `online`
- [ ] 子站正常提供服务

#### 3.2.3 域名绑定验证
- [ ] 代理商换一个域名部署，使用相同授权码
- [ ] 访问子站 → 中间件检测域名不匹配 → 返回 403
- [ ] 日志显示「域名与授权绑定不匹配」

#### 3.2.4 授权码过期
- [ ] 管理后台将该代理商授权码 `expiryAt` 改为过去时间
- [ ] 子站访问 → 中间件检测过期 → 返回 403
- [ ] 日志显示「授权码已过期」

#### 3.2.5 授权码冻结
- [ ] 管理后台「冻结」该授权码
- [ ] 子站访问 → 返回 403
- [ ] 日志显示「授权码已被吊销」
- [ ] 解冻后子站恢复

### 3.3 子站功能验证

#### 3.3.1 核心功能
- [ ] 八字排盘：提交出生信息，返回排盘结果
- [ ] 紫微斗数：排盘正常
- [ ] 奇门遁甲：排盘正常
- [ ] 梅花易数：起卦正常
- [ ] 八字合婚：12 维度合盘正常

#### 3.3.2 品牌隔离
- [ ] 子站 Logo 显示代理商品牌 Logo（非主站 Logo）
- [ ] 子站品牌名显示代理商品牌名
- [ ] 子站「关于我们」「服务条款」显示代理商信息
- [ ] 子站灵珠充值金额独立计算（不与主站共享余额）

#### 3.3.3 数据隔离
- [ ] 子站用户注册 → 写入代理商自己的 MySQL 数据库
- [ ] 主站查询不到子站用户
- [ ] 子站查询不到主站用户
- [ ] 子站订单、佣金记录独立存储

### 3.4 版本更新

#### 3.4.1 在线更新检查
- [ ] 子站定期检查主站版本（`/api/agent/sync` 返回 `latestVersion`）
- [ ] 主站发布新版本 → `APP_VERSION` 更新
- [ ] 子站检测到新版本 → 代理商后台「更新日志」显示提示

#### 3.4.2 更新部署
- [ ] 主站下发新源码包给代理商
- [ ] 代理商重新执行 `bash deploy.sh`
- [ ] 子站 `lastVersion` 更新
- [ ] 子站功能正常，数据无丢失

#### 3.4.3 回滚
- [ ] 代理商部署失败，使用旧版本源码包重新部署
- [ ] 子站恢复正常
- [ ] 数据库未受影响（数据持久化在 D1）

## 四、安全测试

### 4.1 授权码安全

#### 4.1.1 签名验证
- [ ] 篡改授权码载荷（修改 agentId）→ HMAC 验证失败 → 403
- [ ] 篡改授权码签名 → 验证失败 → 403
- [ ] 使用其他代理商的授权码 → agentId 不匹配 → 403

#### 4.1.2 防破解
- [ ] 删除 `APP_LICENSE_KEY` 环境变量 → 中间件拦截 → 403
- [ ] 设置虚假授权码 → 中央服务器验证失败 → 403
- [ ] 断网情况下，子站本地缓存授权状态，宽限期内可用，超期后锁定

### 4.2 权限隔离

#### 4.2.1 路由权限
- [ ] 普通用户访问 `/agent/*` → 重定向到 `/login`
- [ ] 代理商访问 `/admin/*` → 重定向到 `/agent`
- [ ] 代理商 A 登录后，无法看到代理商 B 的数据
- [ ] 代理商无法调用 `/api/admin/*` 接口

#### 4.2.2 数据越权
- [ ] 代理商 A 查询客户列表，只返回 A 的客户
- [ ] 代理商 A 查询佣金，只返回 A 的佣金
- [ ] 代理商 A 尝试传入 B 的 agentId 查询 → 拦截

### 4.3 输入验证
- [ ] 注册接口 XSS 测试：品牌名填 `<script>alert(1)</script>` → 被过滤
- [ ] SQL 注入测试：邮箱填 `' OR 1=1 --` → 参数化查询拦截
- [ ] 手机号格式校验：填字母 → 返回 400
