## 2. 两种代理模式

### 2.1 模式对比

| 对比项 | SaaS 代理 | 源码部署代理 |
|--------|-----------|--------------|
| **部署方式** | 平台托管，无需部署 | 独立部署到自己的 服务器 |
| **数据存储** | 主站数据库，平台统一管理 | 独立数据库，完全自主掌控 |
| **域名** | 平台提供子域名或绑定自定义域名 | 使用自有域名 |
| **品牌定制** | 网站名称 + Logo | 全套品牌定制 |
| **功能权限** | 全功能，平台统一更新 | 全功能，可自主二次开发 |
| **收入归属** | 平台 70% / 代理 30% 分润 | 100% 归代理商 |
| **技术要求** | 无需技术背景 | 需基础部署能力（按文档操作） |
| **功能更新** | 自动同步，即时生效 | 需手动拉取更新 |

### 2.2 选择建议

- **刚起步 / 预算有限 / 不懂技术** → 选 SaaS 代理
- **有客户资源 / 想独立运营 / 长期经营** → 选源码部署代理
- **先试 SaaS，业务稳定后升级源码** → 支持，已付费部分可抵扣

## 4. 首次登录与设置

### 4.1 登录

1. 使用平台提供的邮箱和密码登录
2. 访问 `https://主站域名/login`
3. 系统自动跳转至代理商后台 `/agent`

### 4.2 修改密码

**建议首次登录后立即修改密码。**

密码要求：
- 至少 8 位
- 包含大小写字母 + 数字 + 特殊字符
- 建议 30 天更换一次

### 4.3 品牌设置

**操作路径：** 代理商后台 → 代理设置

| 设置项 | 说明 | 是否即时生效 |
|--------|------|--------------|
| 网站名称 | 代理商的网站品牌名 | 是，刷新后生效 |
| Logo 上传 | 上传品牌 Logo 图片 | 是 |
| 公司名称 | 公司全称（可选） | 是 |
| 联系人 | 联系人姓名 | 是 |
| 联系电话 | 客服电话 | 是 |

**注意：** 品牌名称修改后，网站导航栏、页脚、法律页面会自动同步显示新名称。

## 7. 申请提现

### 7.1 提现规则

| 规则 | 标准 |
|------|------|
| 最低提现金额 | 100 元 |
| 每月提现次数 | 最多 3 次 |
| 手续费 | 5% |
| 审核时间 | 1-3 个工作日 |
| 打款方式 | 微信/支付宝/银行转账 |
| 打款时间 | 审核通过后 3 个工作日内 |

### 7.2 提现步骤

1. 登录代理商后台
2. 进入「结算管理」
3. 点击「申请结算」
4. 输入结算金额
5. 选择收款方式（微信/支付宝/银行转账）
6. 填写收款信息
7. 提交申请
8. 等待管理员审核（1-3 个工作日）
9. 审核通过后打款

### 7.3 结算流程

```
您申请提现
    ↓
管理员审核
  ├─ 通过 → 标记已打款 → 线下转账到您的账户
  └─ 拒绝 → 金额退回您的余额
```

## 8. 源码部署指南

### 8.1 部署前提

| 要求 | 说明 |
|------|------|
| 服务器 | 注册 服务器（免费） |
| 独立域名 | 已购买并解析到服务器 |
| 授权码 | 平台发放的有效授权码 |
| Node.js 18+ | 本地部署需要 |

### 8.2 部署方式

**方式一：GitHub 自动部署（推荐）**

1. 平台将代码推送到您的 GitHub 私有仓库
2. 在 服务器连接 GitHub 仓库
3. 设置环境变量：
   - `APP_AGENT_ID`：您的代理商 ID
   - `APP_LICENSE_KEY`：您的授权码
   - `APP_BOUND_DOMAIN`：您的绑定域名
   - `NEXT_PUBLIC_BRAND_NAME`：您的品牌名称
   - `NEXTAUTH_SECRET`：加密密钥
4. 点击部署
5. 绑定自定义域名

**方式二：本地部署**

1. 下载源码包
2. 安装 Node.js 18+
3. 执行 `npm install`
4. 配置 `.env.production` 文件（填写授权码、域名等）
5. 执行 `npm run build:worker`
6. 执行 `bash deploy.sh`
7. 绑定域名

**方式三：平台代部署（300 元/次）**

1. 提供 服务器和域名
2. 平台代为部署
3. 部署完成后交付使用

### 8.3 配置文件示例

```toml
# .env.production
name = "your-brand-name"
compatibility_date = "2024-09-23"
compatibility_flags = ["nodejs_compat"]

[vars]
APP_AGENT_ID = "agt_xxxxxxxx"
APP_LICENSE_KEY = "xxxx-xxxx-xxxx-xxxx"
APP_BOUND_DOMAIN = "your-domain.com"
NEXT_PUBLIC_BRAND_NAME = "您的品牌名"

[[d1_databases]]
binding = "DB"
database_name = "your-database"
database_id = "您的数据库ID"
```

### 8.4 部署后验证

部署完成后请验证：
- [ ] 网站可正常访问
- [ ] 授权码验证通过（访问 `/api/license/status` 返回 `active`）
- [ ] 域名绑定生效（非绑定域名返回 403）
- [ ] 品牌名称正确显示
- [ ] 用户可注册登录
- [ ] 灵珠充值到账

### 8.5 更新升级

- 平台发布新版本后通知代理商
- 代理商在后台点击「一键升级」
- 系统自动拉取最新代码并重新部署
- 升级过程约 3-5 分钟，期间网站短暂不可用

### 8.6 数据备份

| 数据 | 备份方式 | 频率 |
|------|----------|------|
| 用户数据 | MySQL 自动备份 | 每日 |
| 排盘记录 | 数据库导出 | 建议每周 |
| 系统配置 | 环境变量备份 | 修改时 |

## 9. 授权码说明

### 9.1 什么是授权码

授权码是您作为代理商的身份凭证，用于：
- 源码部署时的身份验证
- 功能更新的权限验证
- 授权状态的在线校验

### 9.2 授权码安全措施

| 措施 | 说明 |
|------|------|
| HMAC-SHA256 签名 | 授权码使用加密签名生成，无法伪造 |
| 域名绑定 | 一个授权码绑定一个域名，不可转移 |
| 在线验证 | 系统定期验证授权状态 |
| 到期失效 | 授权到期后自动锁定核心功能 |
| 远程吊销 | 平台可远程吊销违规代理商授权 |

### 9.3 授权码状态

| 状态 | 说明 | 您的表现 |
|------|------|---------|
| 正常 | 授权有效 | 所有功能正常 |
| 即将到期 | 到期前 7 天 | 显示续费提醒 |
| 已过期 | 超过有效期 | 核心功能锁定，现有数据保留 |
| 已冻结 | 平台冻结 | 全站锁定，联系平台处理 |

### 9.4 授权码丢失怎么办

联系平台管理员，核实身份后重新生成授权码（旧码立即失效）。

### 9.5 查看授权状态

访问您的网站 `/api/license/status`，可查看当前授权状态。

## 10. 常见问题解答

### Q1：SaaS 代理和源码部署代理有什么区别？

**SaaS 代理**是平台托管模式，您不需要管理服务器，用户数据存在平台，平台自动分润给您。
**源码部署代理**是独立部署模式，您拥有自己的服务器和数据库，收入全归您自己，但需要自己管理运维。

### Q2：我刚开始做，选哪个好？

建议先从 SaaS 代理开始。99 元/月，无需技术背景，先验证业务模式。等客户量上来后，再升级到源码部署。

### Q3：SaaS 代理升级到源码部署，之前的费用能退吗？

可以抵扣。已支付的 SaaS 套餐费用按剩余天数比例抵扣源码部署费用。

### Q4：代理商可以自己给用户定价吗？

- **SaaS 代理**：不能。用户充值金额由平台统一设定，代理商获得分润。
- **源码部署代理**：可以。独立部署后，灵珠价格、会员价格均可自行设定。

### Q5：授权码丢了怎么办？

联系平台管理员，核实身份后重新生成授权码（旧码立即失效）。

### Q6：源码部署代理到期不续费会怎样？

- 现有用户可继续使用
- 新用户注册功能锁定
- 灵珠充值功能锁定
- 会员开通功能锁定
- 系统显示「授权已过期」提示
- 续费后所有功能立即恢复

### Q7：代理商能发展下级代理吗？

- **SaaS 代理**：不能。只能发展终端用户。
- **源码部署代理**：可以发展 SaaS 子代理，但必须向平台报备，由平台创建授权码。未报备的视为违规。

### Q8：用户充值的钱是直接进我的账户吗？

- **SaaS 代理**：充值进入平台账户，平台按月结算分润给您。
- **源码部署代理**：充值直接进入您自己的支付账户，100% 归您。

### Q9：平台会不会抢我的客户？

不会。用户通过您的邀请链接注册后，永久归属您的代理。即使平台也无法转移您的客户。

### Q10：如果平台倒闭了怎么办？

- **SaaS 代理**：平台提前 30 天通知，协助导出用户数据。
- **源码部署代理**：您的系统独立运行，不受平台影响。授权码验证改为宽松模式，给您充足时间过渡。

### Q11：源码部署代理可以修改代码吗？

可以。源码部署代理拥有二次开发权，可以修改功能、页面、逻辑等。但以下内容不可修改：
- 授权验证机制
- 在线验证逻辑
- 版权声明

### Q12：代理商需要营业执照吗？

- **SaaS 代理**：不需要，个人即可申请。
- **源码部署代理**：建议有营业执照，但不强制。

### Q13：分润比例可以调整吗？

可以。管理员在后台可以针对单个代理商调整分润比例。默认 30%，最高 38%（钻石代理）。

### Q14：试用版有什么限制？

- 最多 10 个客户
- 7 天有效期
- 全功能体验
- 到期后不付费则功能锁定

### Q15：如何提现？

1. 登录代理商后台
2. 进入「结算管理」
3. 点击「申请结算」
4. 输入提现金额和收款方式
5. 等待管理员审核（1-3 个工作日）
6. 审核通过后打款

## 11. 合作协议要点

### 11.1 双方权利与义务

**平台方：**
- 提供稳定的技术服务和系统维护
- 保障数据安全和系统可用性
- 按时结算分润
- 提供技术支持和培训

**代理商：**
- 合法合规经营
- 不得涉及违法宣传
- 不得私自修改授权机制
- 不得二次倒卖源码
- 按时缴纳授权费用
- 接受平台监管

### 11.2 违约处理

| 违规行为 | 处理方式 |
|----------|----------|
| 私自伪造授权码 | 立即吊销授权，不予退费 |
| 二次倒卖源码 | 立即吊销授权，追究法律责任 |
| 涉及违法宣传 | 冻结授权，整改后恢复 |
| 私自乱收费 | 冻结授权，退还违规收入 |
| 未按时续费 | 功能锁定，续费后恢复 |

### 11.3 合作终止

| 情况 | 处理方式 |
|------|----------|
| 代理商主动终止 | 结算剩余分润，关闭账号 |
| 平台终止（违规） | 吊销授权，不予退费 |
| 平台终止（业务调整） | 提前 30 天通知，退还未使用费用 |
