### 2.3 功能描述（500-1300 字）

```
命理元码SaaS代理运营平台软件是一款面向命理行业的一体化SaaS运营管理系统，
支持多级代理体系和源码独立部署两种商业模式。

系统包含以下核心功能模块：

1. 用户管理系统：支持手机号、邮箱注册登录，密码采用PBKDF2-SHA256加密存储，
   支持第三方OAuth登录。

2. 命理服务引擎：内置八字排盘、紫微斗数排盘、奇门遁甲排盘、梅花易数排盘
   四大命理计算模块，支持用户在线排盘和解读。

3. 代理商管理系统：支持SaaS代理和源码代理两种模式，实现三级代理体系
   （中央站-源码代理-SaaS代理），包含分账机制（源码代理70%/SaaS代理30%）、
   佣金管理、提现审核等完整财务流程。

4. 订单与支付系统：聚合微信支付、支付宝、PayPal、Stripe、ZPay易支付
   五种支付方式，支持卡密兑换，订单全生命周期管理。

5. 内容管理系统：支持命理文章、公告、品牌设置、广告位管理，
   可视化配置站点信息。

6. 系统运维管理：包含一键升级、版本回滚、审计日志、数据备份、
   健康检查等运维功能，支持PM2进程管理。

7. 数据隔离与安全：SaaS代理数据通过agentId隔离，源码代理独立数据库部署，
   API限流、SQL注入防护、XSS防御等安全机制。

8. 代理商自助平台：代理商可自助创建子代理、绑定域名、品牌定制、
   查看经营数据、申请提现。

系统采用Next.js 14+React 18+TypeScript+MySQL技术栈，
支持响应式设计，兼容PC和移动端访问。
```
