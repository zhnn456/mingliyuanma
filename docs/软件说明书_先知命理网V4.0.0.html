一、软件概述

1.1 软件简介

先知命理网系统（以下简称"本系统"）是一款基于中华传统命理学理论，融合现代互联网技术的综合命理服务平台。系统集成了四柱八字排盘、紫微斗数排盘、奇门遁甲排盘、梅花易数起卦等核心命理计算引擎，为用户提供专业的命理测算、运势分析、在线供奉等服务。

系统同时具备完善的SaaS分发体系，支持代理商贴牌部署、独立域名绑定、分润结算等功能，可面向命理行业从业者提供源码部署和贴牌开户服务。

1.2 开发背景

中国传统命理学文化博大精深，但传统排盘计算依赖人工查表，效率低且易出错。随着互联网技术的发展，将命理学与现代计算技术结合，为用户提供准确、便捷的在线排盘与分析服务，成为行业发展趋势。

本系统旨在建立一个专业、准确、易用的命理服务平台，通过自研排盘算法引擎，实现八字、紫微、奇门、梅花等多流派的自动排盘与智能解读，同时为命理行业从业者提供SaaS级部署方案。

1.3 适用范围

本系统适用于以下场景：

  • 命理爱好者在线排盘与测算
  • 专业命理师为客户提供在线服务
  • 命理机构进行贴牌部署与独立运营
  • 命理文化传播与知识普及

1.4 软件架构

本系统采用前后端一体化架构，基于Next.js全栈框架开发。前端使用React组件化开发模式，后端使用Next.js API Routes提供RESTful接口服务。系统采用MySQL关系型数据库存储业务数据，支持Redis缓存（可选）。部署采用PM2进程管理+Nginx反向代理，支持高可用与横向扩展。

三、技术特点

3.1 自研命理算法引擎

系统内置完全自主研发的命理计算引擎，包括：

  • 八字排盘引擎：实现公历转农历、节气计算、天干地支推算、五行分析、十神推演、大运流年计算等完整算法。
  • 紫微斗数引擎：实现紫微144星布局、12宫位排定、四化飞星计算、大限流年推算等算法。
  • 奇门遁甲引擎：实现奇门遁甲置闰法、超神接气、九宫八卦排盘、八神九星八门排定等算法。
  • 梅花易数引擎：实现时间起卦、报数起卦、方位起卦等多种起卦方法，支持64卦分析。

3.2 真太阳时校正

系统内置全球城市经纬度数据库，根据用户选择的出生城市，自动计算该城市与北京时间的时差，进行真太阳时校正，确保排盘时间精确。支持跨天日期自动修正（如23:30+78分钟=次日00:48时自动更新年/月/日）。

3.3 SaaS分发体系

系统具备完整的SaaS分发能力：

  • HMAC-SHA256签名授权：代理商授权码采用数字签名，防篡改、防伪造。
  • 双重验证机制：本地验证+远程验证，支持离线宽限期。
  • 中心化版本控制：统一管理所有代理商的系统版本。
  • 自动分润引擎：订单完成自动计算佣金，支持多级分销。
  • 源码水印防篡改：部署的源码包含授权信息水印。

3.4 安全机制

  • 密码安全：PBKDF2-SHA256算法，100000次迭代哈希存储。
  • 身份认证：JWT Token + Cookie双重认证机制。
  • 权限控制：基于角色的访问控制（RBAC），区分用户/代理商/管理员权限。
  • 输入校验：所有用户输入均经过校验，防止SQL注入、XSS攻击。
  • 频率限制：API接口频率限制，防止恶意请求。
  • 代码混淆：生产环境代码经Webpack混淆加密。

3.5 响应式设计

系统采用Tailwind CSS响应式框架，支持PC端、平板、手机端自适应访问。导航栏在移动端自动切换为汉堡菜单，网格布局根据屏幕宽度自动调整列数。

3.6 自动化部署

系统内置自动化部署脚本（deploy.py），支持：

  • Git仓库自动拉取代码
  • 数据库表结构自动同步
  • 自动化构建（内存限制）
  • PM2进程自动重启
  • 部署后自动验证（健康检查、API测试）
  • 部署日志自动记录到数据库

3.7 版本管理系统

系统内置完整的版本管理机制：

  • 语义化版本号（vX.Y.Z）自动管理
  • 构建时自动注入版本号、Git Commit Hash、构建时间
  • 部署时自动采集Git日志记录更新内容
  • 健康检查API返回完整版本信息

五、软件安装与部署

5.1 环境准备

部署前需准备以下环境：

  1. 安装 Node.js 20.x LTS
  2. 安装 MySQL 8.0+ 数据库
  3. 安装 Nginx Web服务器
  4. 安装 PM2 进程管理器（npm install -g pm2）
  5. 安装 Git 版本控制工具

5.2 数据库初始化

执行数据库初始化脚本，创建全部数据表结构与种子数据：

npm run db:init

该命令执行 scripts/mysql-init.sql 脚本，创建包括用户表、代理商表、订单表、排盘记录表等在内的全部数据表，并插入初始版本号等种子数据。脚本采用幂等设计，支持重复执行。

5.3 配置文件

在项目根目录创建 .env 环境变量文件，配置以下参数：

参数名说明
MYSQL_URLMySQL数据库连接字符串
NODE_ENV运行环境（production/development）
JWT_SECRETJWT签名密钥
PORT服务监听端口（默认3001）

5.4 构建与启动

执行以下命令构建生产环境代码：

npm run build:server

构建时会自动执行版本注入脚本，将当前版本号、Git Commit Hash、构建时间写入系统代码。

启动服务：

PORT=3001 pm2 start npm --name ming8 -- start

5.5 Nginx配置

配置Nginx反向代理，将域名请求转发到Node.js服务：

  • 主域名（ming8.online）代理到 localhost:3001
  • 配置SSL证书（HTTPS）
  • 配置静态资源缓存策略
  • 配置Gzip压缩

5.6 自动化部署

系统内置自动化部署脚本 deploy/deploy.py，支持一键部署：

  • 通过SSH连接服务器
  • 自动拉取最新代码
  • 自动同步数据库表结构
  • 自动构建并重启服务
  • 自动验证部署结果
  • 自动记录更新日志

6.2 代理商端操作

  2. 代理商收到账号后登录代理商后台

  4. 配置域名（子域名或独立域名）
  5. 系统自动生成授权码（HMAC-SHA256签名）

  • 查看客户列表与详情
  • 查看订单与佣金
  • 申请提现
  • 邀请新客户（推荐码）
  • 查看系统更新与版本信息

6.3 管理后台操作

6.3.1 管理员登录

管理员访问 /admin 路径，输入管理员账号密码登录。系统采用RBAC权限控制，不同角色可访问不同模块。

【截图位置：管理员登录页面截图】

6.3.2 用户管理操作

操作步骤：

  1. 进入"用户管理"页面
  2. 可按用户名、邮箱、手机号搜索
  3. 点击用户可查看详情
  4. 可编辑用户信息、调整会员等级、设置标签
  5. 可将用户加入黑名单
【截图位置：用户管理列表截图】

6.3.3 代理商审核操作

操作步骤：

  1. 进入"代理商管理"页面
  2. 查看待审核代理商列表
  3. 审核代理商资质
  4. 通过审核后生成授权码
  5. 配置佣金比例与结算周期

6.3.4 支付配置操作

操作步骤：

  1. 进入"支付配置"页面
  2. 填写微信支付商户号、API密钥、证书信息
  3. 填写支付宝APPID、应用私钥、支付宝公钥
  4. 设置支付回调地址
  5. 保存配置后自动生效

6.3.5 公告发布操作

操作步骤：

  1. 进入"公告管理"页面
  2. 点击"新建公告"
  3. 填写公告标题、内容、图标、链接
  4. 设置排序与启用状态
  5. 保存后公告将以居中弹窗形式展示给未读用户
【截图位置：公告管理页面截图】

6.3.6 版本发布操作

操作步骤：

  1. 进入"版本管理"页面
  2. 点击"发布新版本"
  3. 填写版本号（格式vX.Y.Z）、标题、更新内容
  4. 选择版本类型（主版本/次版本/修订版本）
  5. 可上传安装包与校验码
  6. 可选择"设为最新版本"
  7. 发布后版本记录永久保存

操作步骤：

  5. 可导出财务报表
