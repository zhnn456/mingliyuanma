## 1. 代理商模式概述

### 1.1 什么是代理商

命理网代理商是指经平台授权，以自有品牌运营命理测算服务的合作伙伴。代理商可以使用平台的技术和内容，在自己的品牌下开展业务。

### 1.2 两种代理模式

平台提供两种代理模式，满足不同规模的合作伙伴需求：

| 模式 | 适用人群 | 核心特点 |
|------|----------|----------|
| **SaaS 代理** | 个人创业者、小团队 | 平台托管，无需技术背景，即开即用 |
| **源码部署代理** | 有运营经验的团队 | 独立部署，数据自主，收入全归 |

### 1.3 代理关系

```
┌─────────────────────────────────┐
│         命理网平台（我们）         │
│     提供技术、内容、授权管理        │
└──────────┬──────────────────────┘
           │
    ┌──────┴──────┐
    │             │
┌───▼────┐   ┌───▼─────┐
│SaaS代理 │   │源码部署代理│
│平台托管  │   │独立部署    │
│数据在主站│   │数据在本地  │
│分润模式  │   │收入全归己  │
└───┬────┘   └─────────┘
    │
┌───▼────┐
│  终端用户 │
│归属代理商 │
└────────┘
```

## 2. 两种代理模式对比

### 2.1 对比表

| 对比项 | SaaS 代理 | 源码部署代理 |
|--------|-----------|--------------|
| **部署方式** | 平台托管，无需部署 | 独立部署到自己的 服务器 |
| **数据存储** | 主站数据库，平台统一管理 | 独立数据库，完全自主掌控 |
| **域名** | 平台提供子域名或绑定自定义域名 | 使用自有域名 |
| **品牌定制** | 网站名称 + Logo | 全套品牌定制（名称、Logo、配色） |
| **功能权限** | 全功能，平台统一更新 | 全功能，可自主二次开发 |
| **收入归属** | 平台 70% / 代理 30% 分润 | 100% 归代理商 |
| **技术要求** | 无需技术背景 | 需要基础部署能力（按文档操作） |
| **数据备份** | 平台统一备份 | 代理商自行备份 |
| **功能更新** | 自动同步，即时生效 | 需手动拉取更新，一键升级 |
| **技术支持** | 工单支持 | 工单优先 + 专属客服 |
| **适合人群** | 个人、小团队、试水阶段 | 有一定规模、长期经营者 |

### 2.2 选择建议

- **刚起步 / 预算有限 / 不懂技术** → 选 SaaS 代理
- **有客户资源 / 想独立运营 / 长期经营** → 选源码部署代理
- **先试 SaaS，业务稳定后升级源码** → 支持，已付费部分可抵扣

## 7. 授权码安全机制

### 7.1 授权码的用途

授权码是代理商身份的唯一凭证，用于：
- 源码部署时的身份验证
- 功能更新的权限验证
- 授权状态的在线校验

### 7.2 安全措施

| 措施 | 说明 |
|------|------|
| **HMAC-SHA256 签名** | 授权码使用加密签名生成，无法伪造 |
| **域名绑定** | 一个授权码绑定一个域名，不可转移 |
| **在线验证** | 系统每 24 小时验证授权状态 |
| **到期失效** | 授权到期后自动锁定核心功能 |
| **远程吊销** | 平台可远程吊销违规代理商授权 |
| **版本控制** | 获取更新需验证授权码有效性 |

### 7.3 授权码状态

| 状态 | 说明 |
|------|------|
| **正常** | 授权有效，所有功能正常 |
| **即将到期** | 到期前 7 天提醒续费 |
| **已过期** | 核心功能锁定，现有数据保留 |
| **已冻结** | 平台冻结（如违规操作），需联系平台解冻 |
| **已吊销** | 永久吊销，不可恢复 |

### 7.4 防止代理商违规

**平台通过以下方式杜绝代理商违规：**

1. **防止私自制授权码**
   - 授权码使用 HMAC-SHA256 加密签名
   - 代理商无法自行生成有效授权码

2. **防止私自乱收费**
   - SaaS 代理的用户充值直接进入平台账户
   - 代理商只能获得约定比例的分润
   - 代理商无法直接向用户收费

3. **防止私自开代理**
   - 源码部署代理可发展下级 SaaS 代理
   - 但必须报备平台，由平台创建授权码
   - 未报备的视为违规，可吊销授权

4. **防止掐断联系**
   - 在线验证机制：24 小时验证一次
   - 如果验证失败，3 天后锁定功能
   - 代理商无法绕过验证

## 8. 分润规则与结算

### 8.1 分润计算

**SaaS 代理的分润：**

```
用户充值 100 元 → 获得 1000 灵珠
代理商分润 = 100 × 30% = 30 元
平台收入 = 100 × 70% = 70 元
```

**分润规则：**
- 分润在用户充值时自动计算
- 分润金额记入代理商余额
- 代理商可在后台实时查看
- 提现需申请，审核后打款

### 8.2 结算流程

```
用户充值 → 系统自动分润 → 记入代理余额
                              ↓
                        代理商申请提现
                              ↓
                        管理员审核
                          ├─ 通过 → 打款
                          └─ 拒绝 → 退回余额
```

### 8.3 提现规则

| 规则 | 标准 |
|------|------|
| 最低提现 | 100 元 |
| 每月次数 | 最多 3 次 |
| 手续费 | 5% |
| 审核时间 | 1-3 个工作日 |
| 打款方式 | 微信/支付宝/银行转账 |
| 打款时间 | 审核通过后 3 个工作日内 |

## 9. 源码部署指南

### 9.1 部署前提

| 要求 | 说明 |
|------|------|
| 服务器 | 注册 服务器（免费） |
| 独立域名 | 已购买并解析到服务器 |
| 授权码 | 平台发放的有效授权码 |

### 9.2 部署步骤

**方式一：GitHub 自动部署（推荐）**

1. 平台将代码推送到您的 GitHub 仓库
2. 在 服务器连接 GitHub 仓库
3. 设置环境变量：
   - `APP_AGENT_ID`：您的代理商 ID
   - `APP_LICENSE_KEY`：您的授权码
   - `NEXT_PUBLIC_BRAND_NAME`：您的品牌名称
   - `NEXTAUTH_SECRET`：加密密钥
4. 点击部署
5. 绑定自定义域名

**方式二：本地部署**

1. 下载源码包
2. 安装 Node.js 18+
3. 执行 `npm install`
4. 配置 `.env.production` 文件
5. 执行 `npm run build:worker`
6. 执行 `bash deploy.sh`
7. 绑定域名

**方式三：平台代部署（300 元/次）**

1. 提供 服务器和域名
2. 平台代为部署
3. 部署完成后交付使用

### 9.3 更新升级

- 平台发布新版本后通知代理商
- 代理商在后台点击「一键升级」
- 系统自动拉取最新代码并重新部署
- 升级过程约 3-5 分钟，期间网站短暂不可用

## 10. 常见问题解答

### Q1：SaaS 代理和源码部署代理有什么区别？

**SaaS 代理**是平台托管模式，您不需要管理服务器，用户数据存在平台，平台自动分润给您。
**源码部署代理**是独立部署模式，您拥有自己的服务器和数据库，收入全归您自己，但需要自己管理运维。

### Q2：我刚开始做，选哪个好？

建议先从 SaaS 代理开始。99 元/月，无需技术背景，先验证业务模式。等客户量上来后，再升级到源码部署。

### Q3：SaaS 代理升级到源码部署，之前的费用能退吗？

可以抵扣。已支付的 SaaS 套餐费用按剩余天数比例抵扣源码部署费用。

### Q4：代理商可以自己给用户定价吗？

- **SaaS 代理**：不能。用户充值金额由平台统一设定，代理商获得分润。
- **源码部署代理**：可以。独立部署后，灵珠价格、会员价格均可自行设定。

### Q5：授权码丢了怎么办？

联系平台管理员，核实身份后重新生成授权码（旧码立即失效）。

### Q6：源码部署代理到期不续费会怎样？

- 现有用户可继续使用
- 新用户注册功能锁定
- 灵珠充值功能锁定
- 会员开通功能锁定
- 系统显示「授权已过期」提示
- 续费后所有功能立即恢复

### Q7：代理商能发展下级代理吗？

- **SaaS 代理**：不能。只能发展终端用户。
- **源码部署代理**：可以发展 SaaS 子代理，但必须向平台报备，由平台创建授权码。未报备的视为违规。

### Q8：用户充值的钱是直接进我的账户吗？

- **SaaS 代理**：充值进入平台账户，平台按月结算分润给您。
- **源码部署代理**：充值直接进入您自己的支付账户，100% 归您。

### Q9：平台会不会抢我的客户？

不会。用户通过您的邀请链接注册后，永久归属您的代理。即使平台也无法转移您的客户。

### Q10：如果平台倒闭了怎么办？

- **SaaS 代理**：平台提前 30 天通知，协助导出用户数据。
- **源码部署代理**：您的系统独立运行，不受平台影响。授权码在线验证改为宽松模式（30 天验证一次），给您充足时间过渡。

### Q11：源码部署代理可以修改代码吗？

可以。源码部署代理拥有二次开发权，可以修改功能、页面、逻辑等。但以下内容不可修改：
- 授权验证机制
- 在线验证逻辑
- 版权声明

### Q12：代理商需要营业执照吗？

- **SaaS 代理**：不需要，个人即可申请。
- **源码部署代理**：建议有营业执照，但不强制。如有营业执照需提供复印件。

### Q13：分润比例可以调整吗？

可以。管理员在后台可以针对单个代理商调整分润比例。默认 30%，最高 38%（钻石代理）。

### Q14：试用版有什么限制？

- 最多 10 个客户
- 7 天有效期
- 全功能体验
- 到期后不付费则功能锁定

### Q15：如何提现？

1. 登录代理商后台
2. 进入「收益看板」
3. 点击「申请提现」
4. 输入提现金额和收款方式
5. 等待管理员审核（1-3 个工作日）
6. 审核通过后打款

## 11. 合作协议要点

### 11.1 双方权利与义务

**平台方：**
- 提供稳定的技术服务和系统维护
- 保障数据安全和系统可用性
- 按时结算分润
- 提供技术支持和培训

**代理商：**
- 合法合规经营
- 不得涉及违法宣传
- 不得私自修改授权机制
- 不得二次倒卖源码
- 按时缴纳授权费用
- 接受平台监管

### 11.2 违约处理

| 违规行为 | 处理方式 |
|----------|----------|
| 私自伪造授权码 | 立即吊销授权，不予退费 |
| 二次倒卖源码 | 立即吊销授权，追究法律责任 |
| 涉及违法宣传 | 冻结授权，整改后恢复 |
| 私自乱收费 | 冻结授权，退还违规收入 |
| 未按时续费 | 功能锁定，续费后恢复 |

### 11.3 合作终止

| 情况 | 处理方式 |
|------|----------|
| 代理商主动终止 | 结算剩余分润，关闭账号 |
| 平台终止（违规） | 吊销授权，不予退费 |
| 平台终止（业务调整） | 提前 30 天通知，退还未使用费用 |

## 12. 代码保护机制

### 12.1 保护层次

| 保护层 | 实现方式 | 说明 |
|--------|----------|------|
| **第1层：服务端逻辑保护** | 核心逻辑在 API 路由中 | 八字算法、授权验证、分润引擎等核心逻辑在服务端，前端无法获取 |
| **第2层：前端代码混淆** | webpack-obfuscator | 生产构建时自动混淆前端 JS，变量名变为十六进制，字符串加密 |
| **第3层：域名绑定** | middleware.ts 域名校验 | 授权码绑定域名，换域名无法运行，API 返回 403 |
| **第4层：在线验证** | 10 分钟定时验证 | 每 10 分钟向主站验证授权状态，连续失败 3 次锁定功能 |
| **第5层：授权过期锁定** | middleware.ts 全局拦截 | 授权过期后，除登录页和静态资源外所有页面锁定 |
| **第6层：HMAC 签名** | 授权码加密生成 | 授权码使用 HMAC-SHA256 签名，无法伪造 |
| **第7层：编译保护** | 构建混淆 | 部署后是编译产物，非原始源码 |

### 12.2 前端代码混淆配置

在 `next.config.js` 中配置，只对生产环境的客户端代码生效：

| 混淆选项 | 说明 |
|----------|------|
| 字符串数组旋转 | 字符串打散重组，难以搜索 |
| 控制流扁平化 | 50% 的代码扁平化，逻辑难以跟踪 |
| 字符串加密 | 75% 的字符串用 base64 加密 |
| 变量名替换 | 所有变量名改为十六进制格式（如 `_0x3a2b`） |

**排除项：** 第三方库（vendors、polyfills）不混淆，避免兼容性问题。

### 12.3 域名绑定验证

**配置方式：** 在 `.env.production` 中设置环境变量

```toml
[vars]
APP_BOUND_DOMAIN = "agent.example.com"  # 授权绑定的域名
APP_LICENSE_KEY = "xxxx-xxxx-xxxx-xxxx" # 授权码
APP_AGENT_ID = "agt_xxx"                # 代理商 ID
```

**验证逻辑：**
1. 中间件读取 `APP_BOUND_DOMAIN` 环境变量
2. 获取当前请求的 Host 头
3. 对比域名是否匹配（忽略 www 前缀和端口）
4. 不匹配 → API 返回 403，页面返回"授权验证失败"

### 12.4 在线验证机制

| 参数 | 值 | 说明 |
|------|-----|------|
| 验证间隔 | 10 分钟 | 每 10 分钟向主站验证一次 |
| 失败锁定阈值 | 3 次 | 连续 3 次验证失败后锁定 |
| 网络异常容忍 | 5 次 | 网络错误容忍 5 次才锁定（避免临时网络问题） |
| 验证 API | `/api/license/verify` | 主站验证端点 |
| 状态查询 | `/api/license/status` | 代理商可查看当前授权状态 |

**锁定后允许访问的路径：**
- `/_next/*`（静态资源）
- `/favicon.ico`
- `/api/health`（健康检查）
- `/api/auth/login`（登录）
- `/api/license/*`（授权相关）

### 12.5 授权状态 API

代理商可通过以下接口查看当前授权状态：

```
GET /api/license/status
```

**返回示例：**
```json
{
  "isAgentSite": true,
  "agentId": "agt_xxx",
  "licenseKey": "XXXX-XXXX****XXXX",
  "boundDomain": "agent.example.com",
  "version": "v4.0.0",
  "status": "active",
  "message": "授权正常",
  "checkedAt": "2026-07-31T12:00:00.000Z"
}
```

### 12.6 防止代理商违规

| 风险 | 防护措施 |
|------|----------|
| 私自伪造授权码 | HMAC-SHA256 加密签名，无法伪造 |
| 换域名部署 | 域名绑定验证，不匹配返回 403 |
| 掐断与平台联系 | 在线验证，10 分钟无响应锁定 |
| 修改授权验证逻辑 | 核心逻辑在服务端，前端混淆无法逆向 |
| 二次倒卖源码 | 部署后是编译产物，非源码 |
| 授权过期继续使用 | 过期后全站锁定，仅保留登录页 |

## 14. v2.0 新增功能详情

### 14.1 代理商自助注册

**注册地址：** `/register-agent`

**注册流程：**
1. 填写邮箱、密码、品牌名称、联系人、联系电话
2. 系统自动创建代理商账号 + Agent 记录
3. 自动生成 HMAC 签名授权码
4. 自动生成邀请码（REF + 6位随机字符）
5. 开通 7 天试用期（plan=trial, planExpiry=now+7天）
6. 注册成功后自动登录，跳转代理商后台

### 14.2 邀请用户机制

**邀请链接格式：** `https://主站域名/register?ref=代理商ID`

**流程：**
1. 代理商在后台 → 邀请管理 → 复制邀请链接
2. 客户点击链接注册 → 自动绑定 agentId
3. 客户消费时 → 自动触发分润引擎

**邀请管理页面：** `/agent/invite`
- 邀请链接 + 复制按钮
- 邀请统计：总邀请人数、本月邀请、活跃客户数
- 最近客户列表

### 14.3 分润引擎

**触发时机：** 用户支付成功时自动触发

**分润流程：**
```
用户支付成功
  → 查询用户 agentId
  → 查询代理商 commissionRate（默认 30%）
  → 计算分润金额 = 订单金额 × 分润比例
  → 更新 Order 表（commissionRate, commissionAmount）
  → 更新 Agent 表（totalCommission, pendingCommission, currentMonthGMV）
  → 写入 CommissionRecord 记录
```

**关键参数：**
- 分润比例：默认 30%（可由管理员在后台调整）
- 分润触发：充值、会员开通、供奉消费
- 分润失败不阻断支付流程

### 14.4 套餐付费

**套餐管理页面：** `/agent/billing`

| 套餐 | 价格 | 有效期 | 客户上限 | 功能 |
|------|------|--------|----------|------|
| 试用版 | 免费 | 7天 | 10人 | 基础数据看板、客户管理(10人) |
| 月费版 | 99元/月 | 30天 | 500人 | 完整功能 + 品牌定制 + 自动分润 + 邀请链接 |
| 年费版 | 980元/年 | 365天 | 500人 | 完整功能 + 送2个月 |

**套餐 API：** `/api/agent/billing`
- GET：查询当前套餐信息
- POST：选择/切换套餐（更新 plan, planExpiry, maxCustomers）
