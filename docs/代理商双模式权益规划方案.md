## 一、两种模式核心定位

| 维度 | SaaS代理（saas） | 源码部署代理（source） |
|------|-----------------|----------------------|
| **定位** | 平台托管，即开即用 | 独立部署，数据自主 |
| **适合人群** | 个人创业者、小团队、试水阶段 | 有运营经验的团队、长期经营者 |
| **数据存储** | 主站数据库，平台统一管理 | 独立数据库，完全自主掌控 |
| **收入归属** | 平台70% / 代理30%（分润制） | 100%归代理商（买断制） |
| **技术要求** | 无需技术背景 | 需基础部署能力 |

## 四、分润规则

### 4.1 SaaS代理分润

```
分润基数 = 订单实付金额 - 支付手续费(1%) - 优惠券金额
分润金额 = 分润基数 × 分润比例
```

**分润比例规则：**

| 等级 | 条件 | 分润比例 | 客户上限 |
|------|------|----------|----------|
| 试用代理 | 新注册 | 30% | 10人 |
| 正式代理 | 付费月费/年费 | 30% | 500人 |
| 银牌代理 | 累计客户100+ | 32% | 600人 |
| 金牌代理 | 累计客户500+ | 35% | 800人 |
| 钻石代理 | 累计客户1000+ | 38% | 不限 |

**升级规则：**
- 每月1日自动统计上月数据
- 达到升级条件自动升级，无需申请
- 降级需连续3个月未达到标准
- 旗舰版套餐直接享受35%分润

### 4.2 源码部署代理 — 无分润

- 代理商100%获得所有收入
- 无需平台分润、无需结算
- 收入直接进入代理商自己的支付账户
- 平台不参与资金流转

## 六、授权码差异

### 6.1 SaaS代理授权码

| 属性 | 说明 |
|------|------|
| 生成方式 | HMAC-SHA256签名 |
| 有效期 | 跟随套餐（7天/30天/365天） |
| 域名绑定 | 可选，平台子域名或自定义域名 |
| 功能授权 | bazi, ziwei, qimen, meihua |
| 最大用户数 | 10/500/不限（按套餐） |
| 到期处理 | 功能锁定，付费后恢复 |
| 在线验证 | 是，定期验证授权状态 |

### 6.2 源码部署代理授权码

| 属性 | 说明 |
|------|------|
| 生成方式 | HMAC-SHA256签名（更严格） |
| 有效期 | 1年/永久 |
| 域名绑定 | 必须，绑定代理商自有域名 |
| 功能授权 | bazi, ziwei, qimen, meihua（全功能） |
| 最大用户数 | 不限 |
| 到期处理 | 功能锁定（现有用户可继续使用） |
| 在线验证 | 是，定期验证授权状态和域名 |
| 更新服务 | 授权期内可拉取更新，到期后停止 |

## 七、资质审核流程

### 7.1 统一审核流程

```
代理商提交申请 → 平台审核资料 → 审核通过/拒绝
     ↓                ↓               ↓
填写品牌名      检查资料完整性    通过：发放授权码
填写联系人      检查域名有效性    拒绝：附拒绝原因
填写联系电话    检查品牌合规性
选择代理类型
选择套餐/授权
```

### 7.2 审核差异

| 审核项 | SaaS代理 | 源码部署代理 |
|--------|---------|-------------|
| 品牌名称 | ✅ 必填 | ✅ 必填 |
| 联系人 | ✅ 必填 | ✅ 必填 |
| 联系电话 | ✅ 必填 | ✅ 必填 |
| 登录邮箱 | ✅ 必填 | ✅ 必填 |
| 自有域名 | ❌ 可选 | ✅ 必填 |
| 服务器信息 | ❌ 不需要 | ✅ 需提供（IP/配置） |
| 套餐选择 | ✅ 必选 | ❌ 不适用 |
| 授权选择 | ❌ 不适用 | ✅ 必选 |

## 十一、运营规则补充

### 11.1 SaaS代理运营规则

1. **试用期规则**：试用版7天到期后功能锁定，付费后恢复，试用期间客户数据保留
2. **续费规则**：月费版到期后有3天宽限期，年费版有7天宽限期，宽限期内付费不中断服务
3. **升级规则**：套餐升级差价补齐，立即生效；等级升级自动完成
4. **降级规则**：连续3个月未达到等级标准自动降级，降级有7天缓冲期
5. **退款规则**：试用期内全额退费，7天内退80%，7-30天退50%，超过30天不退

### 11.2 源码部署代理运营规则

1. **授权规则**：年度授权到期后功能锁定（现有用户可继续使用），续费后恢复
2. **更新规则**：授权期内可拉取更新，到期后停止更新但可继续使用
3. **域名规则**：授权码绑定域名，更换域名需重新生成授权码
4. **下级代理规则**：可发展下级SaaS代理，需向平台报备
5. **退款规则**：授权7天内未部署退70%，已部署不退费

### 11.3 通用规则

1. **数据安全**：所有代理商不得泄露用户数据，违者暂停授权
2. **内容合规**：不得虚假宣传算命效果，不得涉及违法内容
3. **支付合规**：SaaS代理通过平台支付收款，源码部署代理自行收款
4. **品牌规范**：不得冒用平台品牌，需使用自有品牌名
5. **技术支持**：SaaS工单支持，源码部署工单优先+专属客服
