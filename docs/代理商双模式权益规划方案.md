# 代理商双模式权益规划方案（V2 修订版）

> 状态：待确认
> 日期：2026-08-11
> 修订说明：V1 把源码部署代理也当作"代理"在主平台后台管理，是错误的。源码部署代理本质是"独立运营商/买断客户"，和主平台只是授权关系。本次重新梳理两种模式的本质区别。

---

## 一、两种模式的本质区别（核心）

### 1.1 一句话定义

| 模式 | 本质 | 一句话 |
|------|------|--------|
| **SaaS代理** | 销售代理 | "帮我卖货，我给你分钱" |
| **源码部署代理** | 买断客户/独立运营商 | "我把源码卖给你，你自己干" |

### 1.2 核心区别对比表

| 维度 | SaaS代理（saas） | 源码部署代理（source） |
|------|-----------------|----------------------|
| **身份定位** | 主平台的销售渠道 | 独立运营商（平台客户） |
| **系统所有权** | 无系统，租用主平台 | 拥有一套完整系统 |
| **服务器** | 主平台服务器 | 代理商自己的服务器 |
| **数据库** | 主平台数据库（共享） | 代理独立数据库 |
| **支付通道** | 主平台的支付账户 | 代理商自己的支付账户 |
| **资金流向** | 客户→主平台→分润给代理 | 客户→代理账户（100%） |
| **客户归属** | 客户在主平台注册，归属于代理 | 客户完全属于代理，与主平台无关 |
| **数据归属** | 平台拥有数据，代理有使用权 | 代理拥有全部数据 |
| **域名** | 主平台子域名或绑定域名（共享服务器） | 代理商自有域名（独立服务器） |
| **技术运维** | 平台负责 | 代理自己负责 |
| **与平台关系** | 代理关系（合作销售） | 授权关系（购买许可） |
| **后台位置** | 在主平台上的 `/agent` 后台 | 在代理自己服务器上的完整后台 |
| **主平台后台权限** | 完整代理后台（管理自己名下客户） | 仅授权管理（授权码/续费/更新/工单） |

### 1.3 关键洞察（V1的错误）

❌ **V1的错误理解**：把源码部署代理也当作"代理"在主平台后台里管理，给他们看"客户管理"、"我的订单"等菜单。

✅ **正确的理解**：
- 源码部署代理的客户数据在**他们自己服务器上**，主平台根本看不到这些数据
- 源码部署代理在主平台上**只有授权管理入口**，看授权码、续费状态、更新服务、技术工单
- 源码部署代理的"完整管理后台"在**他们自己部署的系统上**，和主平台完全独立
- 主平台对源码部署代理的"管理"仅限于：发放授权码、管理授权期限、提供更新服务

## 二、SaaS代理 — 权益规划

### 2.1 SaaS代理在主平台后台的菜单

| 菜单项 | 权限 | 说明 |
|--------|------|------|
| 📊 数据概览 | ✅ | 自己名下客户数、订单数、分润统计 |
| 💰 收益看板 | ✅ | 分润统计（待结算/已结算/累计） |
| 🧾 我的订单 | ✅ | 自己名下客户的订单（只读） |
| 📈 分润明细 | ✅ | 每笔订单的分润记录 |
| 🏦 结算中心 | ✅ | 申请提现、结算记录 |
| 👥 客户管理 | ✅ | 自己名下的客户列表（只读，不可改客户资料） |
| 🔗 邀请管理 | ✅ | 生成邀请码、推荐统计 |
| 📦 套餐管理 | ✅ | 查看当前套餐、升级、续费 |
| 🌐 域名设置 | ✅ | 绑定自定义域名（CNAME到主平台） |
| ⚙️ 代理设置 | ✅ | 品牌名、联系人、联系方式 |
| ❌ 内容管理 | ❌ | 无权管理平台内容 |
| ❌ 会员套餐配置 | ❌ | 无权配置会员套餐和价格 |
| ❌ 支付配置 | ❌ | 无权配置支付通道 |
| ❌ 功能开关 | ❌ | 无权开关命理功能 |
| ❌ 系统更新 | ❌ | 由平台统一更新 |

### 2.2 SaaS代理等级体系与分润比例

| 等级 | 升级条件 | 分润比例 | 客户上限 | 专属权益 |
|------|----------|----------|----------|----------|
| 试用代理 | 注册即获得 | 30% | 10人 | 7天免费试用 |
| 正式代理 | 付费月费/年费 | 30% | 500人 | 全功能、工单支持 |
| 银牌代理 | 累计客户100+ | 32% | 600人 | 优先客服响应 |
| 金牌代理 | 累计客户500+ | 35% | 800人 | 专属客服、优先结算 |
| 钻石代理 | 累计客户1000+ | 38% | 不限 | 专属客服、优先结算、营销支持 |

### 2.3 SaaS代理收费标准

| 套餐 | 费用 | 客户上限 | 分润比例 | 有效期 | 说明 |
|------|------|----------|----------|--------|------|
| 试用版 | 免费 | 10人 | 30% | 7天 | 试用，到期锁定 |
| 月费版 | 99元/月 | 500人 | 30% | 30天 | 适合个人创业者 |
| 年费版 | 980元/年 | 500人 | 30% | 365天 | 送2个月，性价比高 |
| 旗舰版 | 2,980元/年 | 不限 | 35% | 365天 | 直接享受金牌分润 |

### 2.4 SaaS代理分润计算

```
分润基数 = 订单实付金额 - 支付手续费(1%) - 优惠券抵扣金额
分润金额 = 分润基数 × 代理分润比例
```

- 分润状态流转：pending（待结算）→ settling（结算中）→ settled（已结算）→ clawed_back（已退款扣除）
- 结算周期：代理申请结算 → 平台审批 → 打款
- 最低结算金额：100元起
- 退款规则：订单退款后，对应分润自动扣除（clawed_back状态）

### 2.5 SaaS代理运营规则

1. **试用期**：7天到期后功能锁定，付费后恢复，客户数据保留30天后清理
2. **续费宽限**：月费版3天宽限期，年费版7天宽限期，宽限期内付费不中断服务
3. **升级规则**：套餐升级补差价立即生效；等级升级每月1日自动统计
4. **降级规则**：连续3个月未达到等级标准自动降级，降级有7天缓冲期
5. **退款规则**：试用期内全额退费，7天内退80%，7-30天退50%，超过30天不退
6. **支付方式**：所有订单通过平台支付通道收款，代理不直接收款

## 三、源码部署代理 — 权益规划

### 3.1 源码部署代理在主平台的后台菜单（仅授权管理）

⚠️ **关键修改**：源码部署代理在主平台的后台**只有授权管理**功能，不应该有客户管理、订单等菜单（这些数据在他们自己服务器上）。

| 菜单项 | 权限 | 说明 |
|--------|------|------|
| 🔑 授权管理 | ✅ | 查看授权码、授权状态、绑定域名 |
| 📋 授权详情 | ✅ | 授权期限、功能列表、客户上限 |
| 💳 续费管理 | ✅ | 续费授权、续费更新服务 |
| 🔄 更新服务 | ✅ | 检查新版本、拉取更新包 |
| 🎫 技术工单 | ✅ | 提交技术支持工单 |
| ⚙️ 账户设置 | ✅ | 联系人、电话、邮箱 |
| ❌ 数据概览 | ❌ | 数据在代理自己服务器上 |
| ❌ 收益看板 | ❌ | 收入在代理自己账户里 |
| ❌ 我的订单 | ❌ | 订单在代理自己数据库里 |
| ❌ 分润明细 | ❌ | 源码代理无分润 |
| ❌ 结算中心 | ❌ | 源码代理无结算 |
| ❌ 客户管理 | ❌ | 客户在代理自己数据库里 |
| ❌ 邀请管理 | ❌ | 源码代理无邀请码 |
| ❌ 套餐管理 | ❌ | 源码代理是授权制非套餐制 |
| ❌ 域名设置 | ❌ | 域名在代理自己服务器配置 |

### 3.2 源码部署代理在自己服务器上的完整后台

源码部署代理购买源码部署后，在**自己服务器上**拥有完整的管理后台（和主平台功能一致）：

| 功能模块 | 权限 | 说明 |
|----------|------|------|
| 数据概览 | ✅ | 自己站点的客户数、订单数、收入 |
| 用户管理 | ✅ | 自己站点的所有用户 |
| 订单管理 | ✅ | 自己站点的所有订单 |
| 会员套餐 | ✅ | 自行配置会员套餐和价格 |
| 支付配置 | ✅ | 自行配置支付宝/微信/PayPal |
| 内容管理 | ✅ | 文章、知识库、横幅 |
| 功能开关 | ✅ | 自行开关命理功能模块 |
| 卡密管理 | ✅ | 自行生成和管理卡密 |
| 优惠码 | ✅ | 自行创建优惠码 |
| 客服工单 | ✅ | 自行处理客户工单 |
| 系统设置 | ✅ | 品牌名、Logo、域名 |
| 数据导出 | ✅ | 导出自己的数据 |

### 3.3 源码部署代理授权套餐

| 套餐 | 费用 | 授权期限 | 更新服务 | 技术支持 | 说明 |
|------|------|----------|----------|----------|------|
| 年度授权 | 2,980元/年 | 1年 | 含当年更新 | 工单支持 | 适合中小代理 |
| 永久买断 | 6,800元 | 永久 | 含1年更新 | 专属客服 | 适合长期经营 |
| 续费授权 | 1,980元/年 | 续1年 | 含当年更新 | 工单支持 | 年度授权续费 |
| 更新服务续费 | 980元/年 | — | 续1年更新 | 工单支持 | 仅买断用户可购 |

### 3.4 源码部署代理运营规则

1. **授权规则**：
   - 授权码绑定域名（HMAC-SHA256签名）
   - 年度授权到期后功能锁定（现有用户可继续使用已付费功能）
   - 续费后功能恢复
2. **更新规则**：
   - 授权期内可拉取更新包
   - 更新服务到期后停止更新，但可继续使用当前版本
   - 重大版本升级需单独付费
3. **域名规则**：
   - 授权码绑定1个主域名
   - 更换域名需在主平台后台申请重新生成授权码
   - 一个授权码仅支持1个域名
4. **资金规则**：
   - 代理100%获得所有收入
   - 收入直接进入代理自己的支付账户
   - 平台不参与资金流转，无分润无结算
5. **数据规则**：
   - 代理拥有全部数据所有权
   - 平台不备份代理数据（代理自行备份）
   - 代理不得使用平台品牌名，需自有品牌
6. **退款规则**：
   - 授权7天内未部署退70%
   - 已部署不退费
   - 永久买断7天内未部署退80%

## 四、平台管理后台对两种代理的管理

### 4.1 创建代理商时的差异

| 配置项 | SaaS代理 | 源码部署代理 |

| 代理类型 | 必选：SaaS | 必选：源码部署 |
| 品牌名称 | 必填 | 必填 |
| 联系人 | 必填 | 必填 |
| 联系电话 | 必填 | 必填 |
| 登录邮箱 | 必填 | 必填 |
| 自有域名 | 可选 | **必填** |

| 域名管理 | ✅ 子域名/自定义域名 | ❌ 自有域名，仅记录 |
| 功能开关 | ✅ 授权功能列表 | ✅ 授权功能列表（默认全开） |
| 暂停/恢复 | ✅ | ✅ |
| 数据看板 | ✅ 分润、结算数据 | ✅ 授权状态、续费提醒 |
