## 一、业务规则（已确认）

### 1.1 代理类型与权限

| 代理类型 | 创建方式 | 数据可见性 | 收入归属 | 后台位置 |
|:---------|:---------|:-----------|:---------|:---------|
| **SaaS代理** | 自助注册或主站创建 | 主站可见 | 平台70%+代理30% | 主站/agent |
| **源码代理** | 主站创建授权码 | 主站不可见 | 100%归代理 | 自己服务器 |

### 1.2 关键规则

```
✅ SaaS代理不能创建子代理
✅ 源码代理可以发展SaaS子代理（需主站报备，由主站创建）
✅ 转介绍分成：源码代理获得子代理客户收入的20%
✅ 提现仅SaaS代理需要，源码代理无需提现
✅ 主站可见SaaS数据，不可见源码代理数据
✅ SaaS代理可改名换Logo，支持二级域名或自定义域名
```

### 1.3 提现规则（统一）

| 规则项 | 标准 |
|:-------|:-----|
| 最低提现金额 | 100元 |
| 每月最多次数 | 3次 |
| 手续费 | 5% |
| 审核时限 | 1-3个工作日 |
| 打款方式 | 微信/支付宝/银行卡 |

### 2.3 代理商等级（SaaS）

| 等级 | 条件 | 客户名额 | 分润比例 |
|:-----|:-----|:---------|:---------|
| 试用代理 | 新注册 | 10人 | 30% |
| 正式代理 | 付费月费/年费 | 500人 | 30% |
| 银牌代理 | 累计客户100+ | 600人 | 32% |
| 金牌代理 | 累计客户500+ | 800人 | 35% |
| 钻石代理 | 累计客户1000+ | 不限 | 38% |

**升级规则：** 每月1号自动统计，达标自动升级

### 2.4 分润计算

```
分润基数 = 订单实付金额 - 支付手续费(1%) - 优惠券抵扣金额
分润金额 = 分润基数 × 代理分润比例

示例：
用户充值100元
分润基数 = 100 - 1（手续费）- 0（无优惠）= 99元
分润金额 = 99 × 30% = 29.7元
```

### 2.5 转介绍分成

```
源码代理发展SaaS子代理：
  主站创建SaaS子代理 → 子代理客户在主站注册
  收入分配：
    - 主站获得：订单金额 × 70%
    - SaaS子代理获得：订单金额 × 30%（分润）
    - 源码代理获得：订单金额 × 20%（转介绍费）

注意：20%转介绍费从主站收入中支出，不影响SaaS子代理的30%分润
```

```typescript
// src/lib/agent-tier.ts
export async function upgradeAgentTier(agentId: string) {
  const agent = await queryFirst('SELECT * FROM Agent WHERE id = ?', agentId);
  if (!agent) return null;
  
  const customerCount = await queryFirst(
    'SELECT COUNT(*) as cnt FROM User WHERE agentId = ?',
    agentId
  );
  
  const newTier = getTierByCustomerCount(customerCount.cnt);
  if (newTier.rate !== agent.commissionRate) {
    await execute(
      'UPDATE Agent SET commissionRate = ?, tier = ? WHERE id = ?',
      newTier.rate, newTier.name, agentId
    );
  }
  
  return newTier;
}

function getTierByCustomerCount(count: number) {
  if (count >= 1000) return { name: '钻石', rate: 0.38 };
  if (count >= 500) return { name: '金牌', rate: 0.35 };
  if (count >= 100) return { name: '银牌', rate: 0.32 };
  return { name: '正式', rate: 0.30 };
}
```

### 4.4 转介绍分成实现

```typescript
// src/lib/commission.ts
export async function calculateCommission(params: {
  agentId: string;
  orderId: string;
  userId: string;
  productType: string;
  orderAmount: number;
  // ...
}): Promise<CommissionResult> {
  // 计算主代理佣金
  const result = await calculateAgentCommission(params);
  
  // 检查是否有上级代理（转介绍）
  const agent = await queryFirst('SELECT parentAgentId FROM Agent WHERE id = ?', agentId);
  if (agent?.parentAgentId) {
    // 计算转介绍分成（20%）
    const referralCommission = Math.round(result.totalCommission * 0.2 * 100) / 100;
    
    // 保存转介绍分成记录
    await saveReferralCommission({
      agentId: agent.parentAgentId,
      orderId: params.orderId,
      userId: params.userId,
      productType: params.productType,
      orderAmount: params.orderAmount,
      commissionAmount: referralCommission,
      status: 'pending',
    });
    
    result.referralCommission = referralCommission;
    result.referralAgentId = agent.parentAgentId;
  }
  
  return result;
}
```

## 八、总结

### 核心原则

1. **主站管升级不管运营** - 主站负责系统升级、授权管理、提现审核
2. **SaaS代理自主经营** - SaaS代理可自助创建、品牌定制、域名绑定
3. **数据分层隔离** - SaaS数据主站可见，源码数据主站不可见
4. **提现流程规范** - SaaS代理提现需主站审核，支持微信/支付宝/银行卡
