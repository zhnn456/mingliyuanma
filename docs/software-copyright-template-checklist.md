## 二、源码文档格式对照

### 2.1 格式要求

| 项目 | 范本要求 | 你的当前状态 | 检查点 |
|------|---------|-------------|--------|
| 总页数 | 60页（前30+后30） | ⬜ | 不足60页提交全部 |
| 每页行数 | ≥50行 | ⬜ | 含注释和空白行 |
| 页眉 | 软件名称+版本号 | ⬜ | 如"命理元码SaaS代理运营平台软件 V1.0" |
| 页码 | 右上角标注 | ⬜ | 连续编号 |
| 最后一页 | 必须是程序结束页 | ⬜ | 必须以 `}` 结尾，不能写到一半 |
| 空行 | 不要有空行 | ⬜ | Word替换可删除 |
| 启动代码 | 放在文档开始 | ⬜ | 程序入口放在第一页 |
| 打印方式 | 单面打印 | ⬜ | 不能双面 |

### 2.2 源码选取顺序（参考范本建议）

```
前30页（核心逻辑）：
  第1页：程序入口/启动代码
  第2-10页：核心业务逻辑（分账、代理、认证）
  第11-20页：数据访问层（数据库、隔离）
  第21-30页：工具函数（密码、审计、升级）

后30页（API路由+组件）：
  第31-50页：API路由处理
  第51-60页：前端组件（必须以 } 结尾）
```
