## 什么是五行？

五行学说认为，宇宙万物由金、木、水、火、土五种基本元素构成。这五种元素之间存在相生相克的关系，构成了一个动态平衡的系统。

### 五行的基本属性

**木**：具有生长、升发、条达的特性。对应东方、春季、青色、肝脏、仁爱。
**火**：具有炎热、向上、光明的特性。对应南方、夏季、红色、心脏、礼仪。
**土**：具有承载、生化、受纳的特性。对应中央、四季末、黄色、脾脏、诚信。
**金**：具有清洁、肃降、收敛的特性。对应西方、秋季、白色、肺脏、正义。
**水**：具有寒凉、滋润、向下的特性。对应北方、冬季、黑色、肾脏、智慧。

### 五行相生

相生是指一种五行对另一种五行有滋生、促进的作用。相生的顺序为：

**木生火** → **火生土** → **土生金** → **金生水** → **水生木**

- **木生火**：木材燃烧产生火焰，木为火之母，火为木之子
- **火生土**：火焰燃烧后化为灰烬（土）
- **土生金**：金属矿石埋藏在土地之中
- **金生水**：金属表面凝结水珠（古人观察所得）
- **水生木**：水分滋养树木生长

在命理中，生我为印绶（母），我生为食伤（子）。

### 五行相克

相克是指一种五行对另一种五行有制约、抑制的作用。相克的顺序为：

**木克土** → **土克水** → **水克火** → **火克金** → **金克木**

- **木克土**：树木的根系穿透土壤
- **土克水**：土壤筑堤阻挡水流
- **水克火**：水能浇灭火焰
- **火克金**：烈火可以熔化金属
- **金克木**：刀斧可以砍伐树木

在命理中，克我为官杀（管束我），我克为财（我掌控）。

### 五行的乘侮关系

**相乘**（过度的克）：当被克的一方过弱，或克的一方过强时，克制过度称为"乘"。

**相侮**（反向的克）：当被克的一方过强，反而克制了原本克它的五行，称为"侮"或"反克"。

例如：正常情况下水克火，但如果火势过旺而水不足，火反而会将水蒸发，这就是"火侮水"。

### 五行在命理中的应用

- **日主强弱判断**：通过五行旺衰判断日主的强弱
- **用神选取**：根据五行平衡确定补益的五行
- **十神定位**：五行生克是十神关系的基础
- **大运流年**：结合五行生克分析运势变化

### 学习要点

1. 熟记五行相生相克的顺序是基础中的基础
2. 理解五行不仅仅是五种物质，更代表五种能量状态
3. 五行的旺相休囚死随季节变化，这是判断五行强弱的重要依据
4. 实际应用中要同时考虑相生和相克的双重作用
