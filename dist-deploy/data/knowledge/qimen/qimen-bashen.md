## 八神是什么

八神是奇门遁甲中第三层符号，依附于八宫与九星，代表"神助"层面的信息——即传统观念中难以言说的助力或阻力。

## 八神速查表

| 神 | 意象 |
|:--|:--|
| 值符 | 首领、核心、权威之象 |
| 腾蛇 | 虚惊、缠绕、变化不测 |
| 太阴 | 隐匿、细致、暗中相助 |
| 六合 | 合作、聚合、和合之象 |
| 白虎 | 威猛、竞争、冲突压力 |
| 玄武 | 隐晦、暗昧、信息不明 |
| 九地 | 稳定、潜伏、按部就班 |
| 九天 | 高远、进取、强势上扬 |

## 八神的布列规律

八神**依附值符星**布列：值符星在哪个宫，值符神就在该宫；然后按固定顺序（值符、腾蛇、太阴、六合、白虎、玄武、九地、九天）随宫位顺布。八神本身不落中宫。

## 八神与吉凶

- **吉神**：值符（权威）、太阴（隐助）、六合（和合）、九地（稳定）、九天（进取）——多主正面助力
- **凶神**：腾蛇（虚惊）、白虎（竞争）、玄武（暗昧）——多主波折阻力

八神的吉凶同样需要结合宫位、门、星综合判断。

## 记忆要点

八神可以理解为"天时（星）+ 人事（门）之外的心理与气运层"：

> 值符是头，太阴六合是助，九天九地是势，
> 腾蛇白虎玄武是扰。

## 在排盘中怎么看

看排盘时，找目标宫位上的八神：测合作看六合、测竞标看白虎、测暗局看玄武、测出行看九天。八神与九星、八门三合一看，就是奇门对"天时、地利、人和、神助"四层信息的完整呈现。
