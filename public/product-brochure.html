1. 产品概览

知微阁 是一套完整的命理工具平台，涵盖八字、紫微斗数、奇门遁甲、梅花易数四大命理体系，配合祈福广场、会员系统、多支付渠道，形成完整的命理服务商业化闭环。支持源码部署（一次买断独立运营）和SaaS 分站（零成本快速启动）两种模式。

产品定位

面向命理文化创业者、内容创作者、副业从业者，提供开箱即用的命理服务变现平台。无需技术背景，购买源码即可独立部署运营，或以极低成本开通 SaaS 分站快速启动。

核心优势

  • 功能完整：四大命理排盘 + 祈福广场 + 会员体系 + 支付系统 + 管理后台，全栈一体化
  • 商业闭环：用户注册 → 排盘体验 → 付费解锁 → 会员充值 → 供奉祈福，完整变现链路
  • 双模式部署：源码买断独立运营（100% 收益归己）或 SaaS 分站（0 元起步、分润模式）
  • 持续升级：源码客户享 1 年免费升级，后续按年付费升级，持续获取新功能
  • 技术领先：Next.js 14 全栈架构、MySQL 数据库、PM2 进程管理、Nginx 反向代理

5. 源码部署方案

源码部署是一次买断、永久使用、独立运营的方案。购买后获得完整源代码和部署脚本，在自己的服务器上独立运行，100% 收益归己，数据完全自有。

5.1 交付内容

交付项内容说明
源码包构建后的 standalone 产物含 .next 构建产物 + public 静态资源 + server.js
部署脚本deploy/deploy-v8.py一键上传部署，增量更新
升级脚本deploy/update.sh客户侧一键在线升级（检查→下载→备份→解压→迁移→构建→重启）
数据库迁移mysql-migrate-v4.1.0.sql表结构初始化 + 字段升级
配置文件.env 模板 + ecosystem.config.js环境变量 + PM2 进程配置
授权码HMAC 签名的 LIC 授权码绑定客户域名，含升级权益信息
运营手册代理商运营手册 + 源码部署管理员手册完整操作指南
源码部署管理员手册源码部署管理员手册授权码、升级权益、演示账号管理指南
代码保护：交付的源码包经过专业混淆处理（字符串数组化、变量名替换、代码压缩），在不影响运行的前提下保护核心逻辑。客户获得的是可运行的生产包，而非未混淆的源代码。

5.2 升级服务

承诺：购买源码部署的客户，1 年内免费升级所有新功能和修复。1 年后可选择按年续费升级服务（1000 元/年），不续费则继续使用当前版本，不影响运行。

升级权益管控机制

方案费用有效期说明
free 免费0 元（含在购买价中）购买后 1 年免费获取所有更新
annual 年度1000 元/年续费后 1 年到期后续费获取持续升级
none 无——不续费，继续使用当前版本

升级流程（客户侧一键操作）

1
检查更新
客户在服务器执行 bash deploy/update.sh，脚本自动向中央服务器检查新版本
2
授权验证
中央服务器验证授权码签名 → 验证升级权益（是否在有效期内）→ 验证域名绑定 → 生成下载 Token
3
下载升级包
使用 Token 下载增量升级包（2 小时有效，绑定 IP，一次性使用）
4
自动部署
备份当前版本 → 解压升级包 → 执行数据库迁移 → 重启 PM2 服务 → 验证启动成功
安全设计：升级 Token 绑定客户服务器 IP，2 小时后自动过期，一次性使用。即使 Token 泄露，也无法在其他服务器上使用。授权码使用 HMAC-SHA256 签名，无法伪造或篡改升级权益。

6. SaaS 分站方案

无需购买源码，以极低成本开通独立分站，主站提供技术托管和运维，代理商按比例分润。

方案费用分润比例适合人群

专业版299 元/月60%全职运营者

SaaS 分站特点

  • 零技术门槛：无需服务器，开通即用
  • 子域名/独立域名：可使用主站子域名，或绑定自己的域名
  • 品牌定制：自定义站名、Logo、配色、联系方式
  • 独立管理后台：代理商专属后台，管理自己的客户和订单
  • 自动结算：佣金按月自动结算，提现便捷
