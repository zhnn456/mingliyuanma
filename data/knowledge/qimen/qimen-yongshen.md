## 什么是用神

奇门盘中符号众多（九星、八门、八神、三奇六仪），"用神"就是针对所问之事**选取的核心符号与宫位**——它决定了整个分析从哪看起。

## 常见用神速查

| 所问之事 | 用神 |
|:--|:--|
| 事业、职位 | 开门、官禄宫 |
| 财源、生意 | 生门、戊（钱财） |
| 婚姻、合作 | 六合、乙庚 |
| 出行、迁移 | 九天、马星 |
| 学业、考试 | 天辅星、丁 |
| 健康 | 天芮星、乙 |
| 官司 | 白虎、惊门 |
| 竞争、竞标 | 值符、伤门 |

## 三步取用神

**第一步：定类别**——明确问的是事业、财运、婚姻还是其他领域。

**第二步：选符号**——按上表找到对应的门、星、神、仪。门管人事、星管天时、神管气运、六仪管具体事物。

**第三步：看落宫**——找到该符号落于哪一宫，然后看此宫三盘信息：宫内的门、星、神、仪以及宫位五行，综合分析。

## 用神的配合判断

单看一个符号不够，传统讲究"三才合断"：

1. **宫内信息**：该宫的门星神仪组合
2. **宫位五行**：生克关系是否得力
3. **暗干与天盘**：宫内天盘星带的信息

例如测财运：看生门落宫——生门在吉宫、得旺相、逢吉星吉神，则为顺畅之象；若临凶宫凶格，则多波折。
