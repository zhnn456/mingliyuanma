## 命盘上的十二宫

紫微斗数的命盘是一个圆盘，被划分为十二个区域，称"十二宫"，每个宫位对应人生一个领域。

![十二宫位轮盘](/images/knowledge/ziwei/gongwei.svg)

## 十二宫各自代表什么

| 宫位 | 代表领域 |
|:--|:--|
| 命宫 | 本人、先天性格与格局 |
| 兄弟宫 | 兄弟姐妹、平辈关系 |
| 夫妻宫 | 婚姻、配偶 |
| 子女宫 | 子女、晚辈 |
| 财帛宫 | 财运、理财方式 |
| 疾厄宫 | 健康、体质 |
| 迁移宫 | 外出、变动、际遇 |
| 仆役宫 | 朋友、下属、社交圈 |
| 官禄宫 | 事业、职业成就 |
| 田宅宫 | 房产、家庭环境 |
| 福德宫 | 精神世界、福分 |
| 父母宫 | 父母、长辈、文书 |

## 宫位是怎么排出来的

十二宫以**命宫**为起点逆时针排列：命宫→兄弟→夫妻→子女……而命宫的位置由生月与生时决定（"寅宫起正月，顺数生月，逆数生时"）。排出命宫后，其余宫位依次填充。

## 看图小技巧

- **命宫**是核心，先看命宫主星判断整体性格
- 看**三方四正**（本宫 + 对宫 + 三合宫）综合判断，不能只看单宫
- 主星入命宫、财帛宫、官禄宫的配置，是快速了解命盘的第一步

十二宫体系把人生领域完整映射到一张圆盘上，是紫微斗数"一图看人生"的骨架。
