## 分类断卦

根据所问事项的不同，断卦的侧重点也有所不同。

### 事业断卦

看体用生克、本卦变卦的关联，结合官鬼爻和财爻的位置。

### 感情断卦

看夫妻宫对应的卦位，以及卦象中的阴阳和谐程度。

### 财运断卦

看财爻的位置和旺衰，生克制化关系。

### 健康断卦

看官鬼爻和子孙爻的互动，以及五行对应的身体部位。
