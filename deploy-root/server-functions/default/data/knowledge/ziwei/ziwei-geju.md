## 紫微斗数格局

格局是星曜组合形成的特定模式，代表不同的命运特征。

### 经典格局

- **紫府同宫格**：尊贵双全，福气深厚
- **日月并明格**：光明磊落，事业有成
- **七杀朝斗格**：权威显赫，大将之才
- **天梁拱月格**：福寿双全，贵人相助
- **杀破狼格**：变动创新，白手起家

### 格局的判断

格局的判断需要结合主星组合、辅星分布、四化引动等多个因素综合考量。
