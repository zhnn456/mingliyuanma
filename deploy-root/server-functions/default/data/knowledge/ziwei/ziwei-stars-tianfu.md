## 天府星

天府星是南斗之首，财库之星，代表稳定和保守。

### 天府的特性

- **五行**：阳土
- **代表人物**：财库管理者
- **正面特质**：稳重可靠、善于储存、有计划
- **负面特质**：保守固执、缺乏魄力

### 天府在十二宫

- 天府在命宫：性格稳重，善于守成
- 天府在财帛宫：财运稳定，善于储蓄
- 天府在田宅宫：房产运佳，家庭富足

### 天府的组合

天府与紫微同宫：紫府同宫格，福气深厚
天府与武曲同宫：财库相叠，财富丰厚
天府与廉贞同宫：既有原则又有底线
