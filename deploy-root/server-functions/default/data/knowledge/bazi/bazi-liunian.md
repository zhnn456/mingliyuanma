## 流年判断

流年即当年的干支，与命局和大运相互作用产生吉凶。

### 流年作用方式

- **冲**：地支相冲，变动剧烈
- **合**：天干五合、地支六合，牵动关系
- **刑**：地支相刑，是非纠纷
- **害**：地支相害，暗中不利

### 流年判断要点

1. 流年干支对用神的影响
2. 流年与原局、大运的刑冲合害
3. 流年十二神煞的作用
4. 流年引动十神对应的领域
