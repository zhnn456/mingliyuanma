## 四柱排盘方法

排盘是八字分析的第一步，需要准确推算年柱、月柱、日柱、时柱。

### 年柱推算法

年柱以立春为分界。立春之后出生的属于新一年的干支。

### 月柱推算法

月柱以节气为分界。每个月的开始以节（而非气）为准。

正月寅月（立春开始）、二月卯月（惊蛰开始）、三月辰月（清明开始）
四月巳月（立夏开始）、五月午月（芒种开始）、六月未月（小暑开始）
七月申月（立秋开始）、八月酉月（白露开始）、九月戌月（寒露开始）
十月亥月（立冬开始）、十一月子月（大雪开始）、十二月丑月（小寒开始）

### 日柱推算法

日柱需要根据公历日期查表或通过公式计算。

### 时柱推算法

时柱根据出生时辰确定，以日干推算时干。

### 真太阳时校正

由于中国使用统一的北京时间，不同经度地区的实际太阳时存在差异，需要根据出生地的经度进行真太阳时校正。
