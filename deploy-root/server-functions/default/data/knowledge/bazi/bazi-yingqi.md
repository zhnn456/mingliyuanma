## 应期推断

应期是指吉凶事件发生的具体时间，是八字预测的重要环节。

### 应期方法

1. **天干应期**：天干透出或受冲合时
2. **地支应期**：地支逢值或受冲合时
3. **神煞应期**：神煞被引动时
4. **五行应期**：五行旺衰变化时

### 常见应期

- 官星透出→升职机会
- 财星合身→财运到来
- 伤官见官→口舌是非
- 比劫夺财→破财损友
