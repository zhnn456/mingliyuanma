## 十神组合

十神之间的组合会产生特定的命理含义。

### 经典组合

- **伤官配印**：聪明有才，能文能武
- **食神生财**：享受赚钱，生活富足
- **杀印相生**：权利地位，刚柔并济
- **官印相生**：仕途顺利，贵人相助
- **比劫夺财**：竞争激烈，财来财去
- **伤官见官**：是非纠纷，官非口舌

### 十神喜忌

- **喜神**：对命主有利的十神，多为用神对应的十神
- **忌神**：对命主不利的十神，多为忌神对应的十神

### 十神力量判断

十神的力量取决于其对应的天干地支在命局中的旺衰程度。
