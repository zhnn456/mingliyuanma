## 什么是十神？

十神是以日主（日柱天干）为中心，根据其他天干、地支藏干与日主之间的生克关系，以及阴阳属性的不同而定义的十种关系名称。十神是解读八字的重要工具，可以揭示命主在社会关系、事业财富、性格特质等方面的信息。

### 十神的定义方法

十神基于两个维度确定：

1. **五行生克**：生我、克我、我生、我克、同我
2. **阴阳属性**：同性（阳见阳、阴见阴）或异性（阳见阴、阴见阳）

### 十神总表

以日主为中心，其他天干与日主的关系如下：

| 关系 | 同性（偏） | 异性（正） |
|------|-----------|-----------|
| 生我者 | 偏印（枭神） | 正印 |
| 我生者 | 伤官 | 食神 |
| 克我者 | 七杀（偏官） | 正官 |
| 我克者 | 偏财 | 正财 |
| 同我者 | 比肩 | 劫财 |

### 十神详解

#### 1. 正官

正官是克制日主的异性五行，代表约束、规则和责任感。

**正面特质**：正直负责、遵守纪律、有领导能力、受人尊重
**负面特质**：过于保守、缺乏变通、压力过大
**对应人事物**：上司、官方、法律、名誉、事业

#### 2. 七杀（偏官）

七杀是克制日主的同性五行，代表压力、挑战和权威。

**正面特质**：果断勇敢、有魄力、善于管理
**负面特质**：急躁冲动、易惹是非、压力巨大
**对应人事物**：严师、对手、困难、权力、冒险

#### 3. 正印

正印是生扶日主的异性五行，代表学识、长辈和庇护。

**正面特质**：善良仁慈、好学上进、有文化修养
**负面特质**：依赖性强、缺乏主见、过于理想化
**对应人事物**：母亲、师长、学业、证书、房产

#### 4. 偏印（枭神）

偏印是生扶日主的同性五行，代表特殊才能、悟性和偏门学识。

**正面特质**：聪明独特、悟性高、有特殊才能
**负面特质**：性格孤僻、思维怪异、不合群
**对应人事物**：继母、特殊技艺、宗教玄学、非主流学识

#### 5. 正财

正财是日主克制的异性五行，代表稳定的财富和正当收入。

**正面特质**：务实节俭、勤劳致富、婚姻稳定
**负面特质**：过于吝啬、缺乏魄力、守财奴
**对应人事物**：正妻、工资收入、固定资产、稳定财源

#### 6. 偏财

偏财是日主克制的同性五行，代表意外之财和投资收入。

**正面特质**：慷慨大方、善于理财、机会多
**负面特质**：挥霍浪费、冒险投机、感情复杂
**对应人事物**：偏妻（情人）、投资收益、意外之财、商业

#### 7. 食神

食神是日主生发的异性五行，代表才华、享受和口福。

**正面特质**：温和善良、有才艺、懂生活、乐观
**负面特质**：贪图享乐、懒散、过于放纵
**对应人事物**：女儿、才华展示、美食、艺术创作

#### 8. 伤官

伤官是日主生发的同性五行，代表才智、清高和创新。

**正面特质**：聪明过人、有创造力、追求自由
**负面特质**：傲慢清高、言辞尖锐、不服管束
**对应人事物**：儿子、技术创新、艺术天赋、自由职业

#### 9. 比肩

比肩是与日主同五行同阴阳的干支，代表自我、兄弟和朋友。

**正面特质**：独立自主、意志坚定、团结互助
**负面特质**：固执己见、好胜心强、易招小人
**对应人事物**：兄弟、朋友、同事、竞争者

#### 10. 劫财

劫财是与日主同五行异阴阳的干支，代表合作、竞争和分享。

**正面特质**：热情大方、善于社交、协同合作
**负面特质**：爱争抢、易破财、感情用事
**对应人事物**：姐妹、合作伙伴、竞争对手、朋友

### 十神的组合效应

十神单独分析意义有限，更重要的是看十神之间的组合：

- **官印相生**：正官配正印，事业有成，德才兼备
- **食神生财**：食神配正财，富贵双全，安逸享福
- **伤官见官**：伤官与正官相遇，易有是非官司
- **比劫夺财**：比肩劫财旺而财弱，容易破财
- **杀印相生**：七杀配正印，威权在握，掌握大权

### 学习要点

1. 十神关系以日主为核心，必须先确定日主的天干
2. 十神的吉凶取决于其在命局中的配置和旺衰
3. 十神没有绝对的好与坏，关键在于是否得位和制化
4. 地支藏干的十神同样重要，需要熟练掌握地支藏干
5. 十神的组合效应比单个十神更有分析价值
