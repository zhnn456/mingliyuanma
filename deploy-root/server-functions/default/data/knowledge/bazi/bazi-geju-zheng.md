## 格局概述

格局是八字分析的重要维度，不同格局对应不同的富贵层次。

### 正格

正格是普通格局，按照月令取格，分为八种：
- 正官格、七杀格
- 正印格、偏印格
- 正财格、偏财格
- 食神格、伤官格

### 变格（特殊格局）

- **从格**：全局某种五行极旺
- **化气格**：天干五合化气
- **专旺格**：一种五行特别旺盛

### 格局的判断

格局的成败取决于用神是否得力、五行是否平衡、结构是否清纯。
