## 什么是用神

用神是对命主最有利的五行或十神，是八字中的关键平衡点。

### 取用神的方法

1. **扶抑法**：身旺则抑，身弱则扶
2. **调候法**：寒则暖之，热则凉之
3. **通关法**：两行相战，通关调和
4. **病药法**：有病方为贵，无伤不是奇

### 用神的作用

- 用神得力：富贵可期
- 用神受损：运势受阻
- 用神到位：逢凶化吉

### 忌神

忌神是对命主最不利的五行，需要注意忌神当道的年份。
