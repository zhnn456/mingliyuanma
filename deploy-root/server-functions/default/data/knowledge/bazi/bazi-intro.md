## 什么是四柱八字？

四柱八字，又称"生辰八字"、"子平术"，是中国传统命理学中最核心的流派之一。它以一个人的出生年、月、日、时为基础，分别对应四个"柱"——年柱、月柱、日柱、时柱，每柱由一个天干和一个地支组成，共八个字，故称"八字"。

### 八字的基本结构

一个完整的八字排盘如下示例（假设某人的八字）：

```
年柱  月柱  日柱  时柱
 甲    丙    戊    庚
 子    寅    辰    申
```

- **年柱**：出生年份的天干地支（如甲子年）
- **月柱**：出生月份的天干地支（如丙寅月）
- **日柱**：出生日的天干地支（如戊辰日）
- **时柱**：出生时辰的天干地支（如庚申时）

### 八字中的核心概念

**日主（日元）**：日柱的天干代表命主本人，是八字分析的核心。如上例中，戊土就是日主。

**四柱的含义**：

- **年柱**：代表祖上、父母、童年运势
- **月柱**：代表父母、兄弟姐妹、青年运势、季节五行旺衰
- **日柱**：代表自己和配偶，中年运势
- **时柱**：代表子女、晚年运势、事业成果

### 排盘的基本步骤

#### 1. 确定年柱

年柱以立春为分界，而非农历正月初一。例如，2024年2月4日（立春）之后出生的人才属甲辰年。

#### 2. 确定月柱

月柱以节气为分界：

| 月份 | 节气 | 地支 |
|------|------|------|
| 正月 | 立春~惊蛰 | 寅 |
| 二月 | 惊蛰~清明 | 卯 |
| 三月 | 清明~立夏 | 辰 |
| 四月 | 立夏~芒种 | 巳 |
| 五月 | 芒种~小暑 | 午 |
| 六月 | 小暑~立秋 | 未 |
| 七月 | 立秋~白露 | 申 |
| 八月 | 白露~寒露 | 酉 |
| 九月 | 寒露~立冬 | 戌 |
| 十月 | 立冬~大雪 | 亥 |
| 十一月 | 大雪~小寒 | 子 |
| 十二月 | 小寒~立春 | 丑 |

月柱的地支固定，天干则根据年柱天干，用"五虎遁"口诀推算。

#### 3. 确定日柱

日柱需要根据公历生日，通过公式或查阅万年历来确定。计算公式较为复杂，推荐使用专业排盘软件或查阅万年历。

#### 4. 确定时柱

时柱的地支根据出生时辰确定（23:00-01:00为子时，以此类推），天干则根据日柱天干，用"五鼠遁"口诀推算。

### 五虎遁（年上起月法）

```
甲己之年丙作首，乙庚之岁戊为头。
丙辛之年寻庚上，丁壬壬寅顺水流。
若问戊癸何处起，甲寅之上好追求。
```

### 五鼠遁（日上起时法）

```
甲己还加甲，乙庚丙作初。
丙辛从戊起，丁壬庚子居。
戊癸何方发，壬子是真途。
```

### 八字分析的基本框架

1. **看强弱**：分析日主在命局中的旺衰状态
2. **定格局**：确定八字的格局类型（正格、变格等）
3. **取用神**：根据日主强弱选择最需要的五行
4. **看十神**：分析十神的配置和相互关系
5. **看大运**：结合大运流年分析运势起伏

### 学习要点

1. 排盘是第一步，也是最重要的基本功，必须熟练掌握
2. 节气是八字排盘的关键，务必记住每个月的起始节气
3. 初学者可以使用排盘软件辅助，但要理解背后的原理
4. 八字的本质是分析五行能量分布和相互作用

### 推荐学习路径

1. 先掌握天干地支和五行生克的基础知识
2. 学习如何正确排盘
3. 了解十神的含义和用法
4. 学习判断日主旺衰和选取用神
5. 最后学习大运流年的分析方法
