📋 执行摘要：核心诊断

网站当前处于"搜索隐形"状态，存在多个P0级阻断性问题
⚠️ 最关键发现
site:ming8.online 搜索返回零结果——网站目前完全未被搜索引擎收录。 根本原因不是"新站还没被抓取"，而是多个技术层面的SEO阻断导致爬虫无法有效发现和索引内容。 54篇高质量知识库文章因客户端渲染（CSR）对搜索引擎完全不可见。

问题严重度分布

优先级问题数说明
P0 - 阻断级3必须立即修复，否则一切SEO努力都无效
P1 - 高优先级5严重影响排名能力和流量获取
P2 - 中优先级4影响长期增长和竞争力

🚨 P0 阻断级问题（必须立即修复）

这些问题直接导致搜索引擎无法发现、抓取和索引你的网站内容
1. 知识库内容客户端渲染（CSR），搜索引擎完全不可见 P0
/knowledge 页面使用了 'use client' 指令，所有54篇知识文章通过 /api/knowledge 接口动态加载。 这意味着爬虫访问页面时只能看到空壳HTML，所有文章内容对搜索引擎完全不可见。

影响范围：54篇高质量原创内容（涵盖八字、紫微斗数、奇门遁甲、梅花易数、阴阳五行等）全部浪费——这些本该是获取长尾搜索流量的核心资产。

涉及文件：
  • src/app/knowledge/page.tsx — 使用了 'use client'
  • src/app/(member)/bazi/page.tsx — 使用了 'use client'
  • src/app/(member)/ziwei/page.tsx — 使用了 'use client'
  • src/app/(member)/qimen/page.tsx — 使用了 'use client'
  • src/app/(member)/meihua/page.tsx — 使用了 'use client'
将知识库页面重构为服务端渲染（SSR）或静态生成（SSG）。为每篇文章创建独立的静态页面路由（如 /knowledge/bazi-intro）， 在构建时直接将Markdown内容渲染为HTML。Next.js App Router支持在Server Component中直接读取Markdown文件并渲染，无需API调用。 工具页面（八字排盘等）可在保持交互功能的同时，增加服务端渲染的SEO内容区块（如排盘说明、FAQ、术语解释）。
2. 网站未被搜索引擎收录（零索引） P0
site:ming8.online 搜索返回零结果。虽然 robots.txt 和 sitemap.xml 配置正确， 但网站从未被提交到 Google Search Console 和 百度搜索资源平台。 同时，由于上述CSR问题，即使爬虫来了也抓不到有效内容。
① 注册并验证 Google Search Console（目标市场含海外中文用户）和 百度搜索资源平台（国内核心流量来源）。 ② 提交 sitemap.xml。 ③ 使用百度主动推送API加速收录。 ④ 在百度站长工具中申请"新站保护"加速审核。 ⑤ 确保服务器响应速度 < 500ms，爬虫抓取预算不浪费。
3. Sitemap仅含12个URL，知识库54篇文章未纳入 P0
当前 sitemap.ts 仅手动列出了12个URL。54篇知识文章没有独立URL，因此无法被纳入sitemap。 竞争对手（中华易经网、卜易居等）的sitemap通常包含数百到上千个URL。
为每篇知识文章创建独立路由（/knowledge/[slug]），并自动生成到sitemap中。 目标：sitemap从12个URL扩展到至少70+个URL（12个功能页 + 54篇知识文章 + 后续新增的SEO着陆页）。

⚡ P1 高优先级问题

这些问题严重影响排名能力和流量获取，需在1-2周内修复
4. 完全没有结构化数据（Schema Markup） P1
全站零JSON-LD结构化数据。没有 Organization、WebSite、Article、FAQPage、BreadcrumbList 等任何Schema类型。 这意味着完全错过了搜索结果中的富摘要（Rich Snippets）、知识面板、站点链接等SERP特性。
立即实施以下Schema：
  • Organization — 全站布局，含名称、Logo、联系方式、社交账号
  • WebSite + SearchAction — 启用站内搜索框出现在搜索结果
  • Article — 每篇知识文章页，含标题、作者、发布/更新时间、封面图
  • FAQPage — 排盘工具页面的常见问题区域
  • BreadcrumbList — 所有内页的面包屑导航
  • HowTo — 排盘操作指南页面
5. 排盘工具页面内容过于稀薄 P1
八字排盘页（/bazi）仅有一个表单和标题，文字内容不足50字。紫微斗数、奇门遁甲、梅花易数页面同样如此。 搜索引擎对薄内容页面（Thin Content）给予极低排名。竞争对手的排盘页面通常包含：排盘说明、术语解释、使用教程、FAQ、相关文章推荐等数百到数千字内容。
每个工具页面增加以下SEO内容区块：
  • 排盘工具介绍（300-500字）— 解释工具原理和功能
  • 使用教程（200-300字）— 图文并茂的操作指南
  • FAQ区域（5-10个常见问题）— 带FAQPage Schema
  • 相关术语表 — 如十神、大运、流年等概念解释
  • 相关文章推荐 — 链接到知识库对应文章

7. 缺少Canonical URL和Open Graph图片 P1
没有 canonical 标签可能导致重复内容问题。没有 og:image 导致社交媒体分享时无预览图，影响点击率和分享传播。
在 layout.tsx 的metadata中添加 metadataBase、alternates.canonical，为每个页面设置OG图片（推荐1200×630px）。
8. 内部链接架构缺失 P1
首页仅链接到4个工具页面，知识库文章之间没有文本锚链接，工具页面没有链接到相关知识文章。 内部链接是传递页面权重、建立主题集群的关键。
建立主题集群架构：以4个工具页面为支柱页（Pillar Page），各自关联相关知识文章形成集群。 文章之间添加上下篇和相关文章链接。工具页面底部添加"相关知识"区块。

📊 P2 中优先级问题

影响长期增长和竞争力，需在1-2个月内规划实施
9. 没有博客/内容更新机制 P2
竞争对手（345club.com、zhouyihui.com等）每天发布运势、生肖、星座类文章，持续获取长尾流量。 知微阁目前没有内容更新机制，搜索引擎缺乏回访理由。
10. 缺少SEO着陆页体系 P2
竞争对手针对"八字算命""免费排盘""今日运势""生肖配对"等高搜索量关键词创建了专门的着陆页。 知微阁缺少此类页面，错失大量搜索流量。
11. 代码混淆可能影响页面性能 P2
webpack-obfuscator 虽然关闭了控制流扁平化，但仍会增加JS包体积约15-30%。 需验证Core Web Vitals（LCP < 2.5s, INP < 200ms, CLS < 0.1），确保不影响页面加载速度和排名。
12. 无外链建设和品牌曝光 P2
新域名、零外链、零品牌搜索量。搜索引擎无法判断网站的权威性和可信度（E-E-A-T）。

import { readFileSync, readdirSync } from 'fs';
import path from 'path';

// 静态生成所有文章路径
export async function generateStaticParams() {
  const articlesDir = path.join(process.cwd(), 'data/knowledge');
  const slugs = getAllSlugs(articlesDir);
  return slugs.map(slug => ({ slug }));
}

// 动态生成每篇文章的元数据
export async function generateMetadata({ params }) {
  const article = await getArticle(params.slug);
  return {
    title: article.title,
    description: article.summary,
    alternates: { canonical: `/knowledge/${params.slug}` },
    openGraph: {
      title: article.title,
      description: article.summary,
      type: 'article',
      images: article.image ? [article.image] : [],
    },
  };
}

// 服务端渲染文章内容
export default async function ArticlePage({ params }) {
  const article = await getArticle(params.slug);
  const related = await getRelatedArticles(article);
  return (
    <article>
      <JsonLd data={articleSchema(article)} />
      <h1>{article.title}</h1>
      <div dangerouslySetInnerHTML={{ __html: article.html }} />
      <RelatedArticles articles={related} />
    </article>
  );
}

// src/app/sitemap.ts（优化后）
export default async function sitemap() {
  const baseUrl = 'https://ming8.online';
  const staticPages = [
    { url: baseUrl, priority: 1.0, freq: 'daily' },
    { url: `${baseUrl}/bazi`, priority: 0.9, freq: 'weekly' },
    // ... 其他静态页面
  ];

  // 自动扫描知识库文章
  const articles = await getAllKnowledgeSlugs();
  const articlePages = articles.map(slug => ({
    url: `${baseUrl}/knowledge/${slug}`,
    lastModified: new Date(),
    changeFrequency: 'monthly',
    priority: 0.7,
  }));

  return [...staticPages, ...articlePages];
}
